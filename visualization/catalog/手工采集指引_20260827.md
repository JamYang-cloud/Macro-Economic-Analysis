## 一、系统自动抓取可行性结论（2026-08-27 实测 5 轮）

| 项目 | 结论 |
|---|---|
| 网站可访问 | ✅ playwright 打开正常 |
| 指标树浏览 | ✅ 月度数据 → 价格指数 → 分类指数（按 2026-/2021-2025/2016-2020/-2015 分段） |
| 全局搜索 | ✅ 搜索"社会消费品零售总额"返回 427 条结构化结果（含指标/地区/时间/数值） |
| 最新值获取 | ✅ 无需登录即可见（如社零当期值 39022.3 @ 2026-07） |
| 历史全序列/详情页/导出 | ⚠️ SPA 交互复杂 + "下载"功能要求登录（账号+验证码），系统无法自动完成 |
| **结论** | **全自动批量抓取不可行；手工采集完全可行** |

## 二、手工采集通用流程

1. 打开网站 → 顶部搜索框输入指标名（或走栏目树）
2. 搜索结果点指标名 → 进入指标详情页（如需登录，注册/登录后使用）
3. 详情页设置时间范围（如 2021-01 ~ 2026-07）→ 点击"下载/导出 Excel"
4. 核对数值与清单区间 → 保存到本地 → 按第五节回流

## 三、重点指标查找路径（对应缺失清单优先项）

| 变量 | 查找方式 | 备注 |
|---|---|---|
| 核心CPI（inf.cpi_core，缺 59 月 2021-08~2026-06） | 月度数据 → 价格指数 → 居民消费价格分类指数 → 全国居民消费价格分类指数 (2021-2025) / (2026-) → 展开"不包括食品和能源"（上年同月=100） | 官方核心CPI口径 |
| PPIRM（inf.ppirm，缺 59 月 2021-08~2026-06） | 月度数据 → 价格指数 → 工业生产者价格指数 → "工业生产者购进价格指数"（PPIRM） | 与 nbs_monthly_archive 已有 2026-07 衔接 |
| 社零季调环比（gro.retail_sa_mom，缺 23+33 月） | 搜索"社会消费品零售总额 环比"；或 月度数据 → 批发和零售业 → 社会消费品零售总额 → 季调环比 | 注意选"季调环比"口径非普通环比 |
| 固投官方季调环比（gro.fai_official_samom，缺 14 月 2021-09~2022-10） | 月度数据 → 固定资产投资（不含农户）→ 季调环比 | |
| 社零/固投/PMI 等月度宏观（零星缺口） | 搜索指标名 → 对应年度段 | |
| 出口/进口同比（gro.export_yoy/import_yoy，13/9 月） | 月度数据 → 对外经济贸易 → 进出口 | 滞后约 1 年属发布节奏，可能无法提前 |

## 四、统计局无此指标（清单中标记但统计局补不了，需其他源）

| 变量 | 缺口 | 数据归属 |
|---|---|---|
| hh.deposit_hist（居民存款历史，172 月） | 央行数据 | 人行官网/金融机构信贷收支表 |
| afre_yoy / cre.tsf_stock / tsf_flow（社融系，84 月等） | 央行数据 | 人行官网调查统计司（Phase 2 已自建官方序列） |
| mar.market_balance（融资融券，15 月） | 交易所数据 | 沪深交易所官网 |
| mkt.hs300_510300 等基金净值 | 基金公司/交易所 | 非统计局范畴 |

**判断规则**：清单中 reason=SOURCE_GAP 且指标在统计局月度发布范围（CPI/PPI/社零/固投/PMI/工业）→ 统计局可补；
reason=NOT_RELEASED 且属央行/交易所数据 → 统计局无此指标。

## 五、补录回流流程（Phase 2 铁律）

1. 导出的 Excel/CSV 整理为标准格式（日期列 + 值列，utf-8）
2. 存为 data_raw_v3 下的新文件（如 `stats_gov_cpi_core_20260827.csv`），
   **不得覆盖既有文件**
3. 更新 manifest（step7_7_update_manifest.py 模式）→ 重建 Excel 共享包
4. 重跑 Step 2.2（standardized）~ 2.9（QC）相关环节，或至少：
   snapshot_sync.py 同步可视化快照 → 可视化中对照新旧序列
5. RECORD 追加采集记录（来源/时间/核验方式）
