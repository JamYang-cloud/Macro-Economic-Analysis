# 宏观股市罗盘_日本 · JP2.3 M4 稳健性检验说明（2026-09-06）

## 一、范围（JP1.9 冻结规则落实）

三条稳健性检验：R1 Model A vs Model B（call 的 ASSUMED 段敏感性）、R2 M2 revision 多档 stress（±0.25/0.5/1.0pp）、R3 JP2.2 中日对照的 CN 截断敏感性。方法学说明：JP1.9 冻结的 M2 stress 规则在草案里是"平移重算"，但秩相关（Spearman）与五分位分组对单调平移**数学上不变**——平移不改变排序。因此把 stress 忠实实现为"revision 噪声扰动"：对 M2 canonical 逐点叠加 N(0,σ)（官方订正会非单调地改变部分月份的值，扰动排序），100 次重抽 Spearman 看 rho 分布。这是对冻结规则在秩方法下的正确翻译，已在脚本与本文记录。

## 二、结果

R1（call ASSUMED 段）：Model A（官方 1998+）36m rho -0.403 → Model B（并入 1995-97 镜像 ASSUMED 段 36 月）**-0.496**（负相关加强）；60m -0.258 → **-0.414** 加强；120m **+0.026 → -0.194 符号翻转**。解读：JP2.0 报的"call 与 120m 收益无关联（+0.03≈0）"是样本截断假象——A 口径把 1995-97 的高利率决策点排除在 120m 检验外，而这些点（利率 2.2%+ 高位、泡沫破裂后段）未来十年恰是日本最深的阴跌（到 2005-07 日经仍腰斩以下）；纳入后长端负相关显现。方向性主结论（利率高位→未来收益低）在 A/B 下均稳健且 B 更强；120m 的"无关联"表述应修正为"弱负相关（早期段纳入后更明显）"。
R2（M2 revision 噪声）：σ=0.25/0.5/1.0pp 下 rho 均值 0.085-0.089、P2.5-P97.5 区间 [0.016, 0.163]，零扰动 0.079——M2 与未来收益的弱关联（|rho|<0.1）在任何修订噪声幅度下都不翻转，"日本 M2 对股市区分度低"结论稳健。
R3（CN 截断）：JP2.2 中国窗主结论（持 3 年中位 +16.9%、负收益 30%）在窗口去尾（决策止 2020-01）后为 +15.7% / 32%——不依赖尾段，"中国 2015-2025 持有体验显著优于日本 1995-2005"的对照稳健。

## 三、对 JP2.0-2.2 结论的净影响

JP2.0 全部主方向结论稳健（利率/汇率/宽松量价与收益的关系方向不变，仅 120m call 从"无关联"修正为"弱负相关"）；JP2.1 regime 分组不受修订影响（regime 归属与 M2 值独立分层后组内差异更稳）；JP2.2 中日对照稳健。无任何主结论在压力下翻转——JP2 描述性证据层可进入汇总（JP2.4）。
