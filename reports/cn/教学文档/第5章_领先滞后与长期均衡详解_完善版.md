# 第 5 章：领先滞后与长期均衡详解——从相关到预测、从重叠收益到长期约束

> **完善版说明**：本章在原始《第 5 章：领先滞后与长期均衡详解》的框架上系统扩展。原稿已经明确区分了三类问题：
>
> 1. **短中期关系**：相关、滞后扫描、Granger；
> 2. **长期预测**：3/5/10 年未来收益、重叠样本、block bootstrap；
> 3. **长期均衡**：单位根、协整、VECM。
>
> 本版保留这些主线和原项目已经得到的阶段性结果，但进一步做四件事：
>
> - 把“相关”“领先”“预测”“Granger”“因果”“长期均衡”严格分层；
> - 补充时间序列自相关、重叠收益、HAC 标准误、bootstrap、有效样本量的数学逻辑；
> - 明确 ADF、Johansen、VECM 的适用前提，特别指出 **标准 Johansen 协整要求进入系统的变量具有兼容的积分阶数，不能把一个明显 \(I(0)\) 序列和一个 \(I(1)\) 序列机械解释成标准协整关系**；
> - 把阶段性结果重新放到“证据强度”的框架下解释，避免把统计关联直接升级为结构因果。
>
> 因此，本章的目标不是简单回答“哪个因子显著”，而是回答：
>
> \[
> \boxed{
> \text{我们到底有多大把握认为当前状态对未来收益含有可重复的信息？}
> }
> \]

---

# 5.0 从“共同变化”进入“时间关系”

第四章 PCA 解决的是：

\[
X_t\rightarrow F_t
\]

即：

> 多个变量能否压缩成少数共同经济状态？

第五章开始回答：

\[
F_t\rightarrow R_{t+h}
\]

即：

> 当前状态与未来收益有没有关系？

这是研究逻辑上的重大变化。

前四章主要研究：

\[
P(X)
\]

第五章开始研究：

\[
P(Y_{t+h}\mid X_t)
\]

其中：

- \(X_t\)：决策时点 PIT-safe 状态；
- \(Y_{t+h}\)：未来收益或未来风险结果。

这一步才真正进入：

\[
\boxed{\text{predictive inference}}
\]

---

# 5.1 五种“关系”必须严格区分

很多研究会把以下词混在一起：

```text
相关
领先
预测
Granger 因果
结构因果
```

它们不是同一层级。

---

## 5.1.1 同期相关

\[
Corr(X_t,Y_t)
\]

回答：

> 两个变量是否同涨同跌？

它甚至不要求时间先后。

---

## 5.1.2 滞后相关

\[
Corr(X_t,Y_{t+h})
\]

回答：

> 当前 X 和未来 Y 是否存在线性关联？

有时间方向，但仍然不是因果。

---

## 5.1.3 预测增量

如果：

\[
E(Y_{t+h}\mid X_t,Z_t)
\]

比：

\[
E(Y_{t+h}\mid Z_t)
\]

预测得更好，则 X 提供：

\[
\boxed{\text{incremental predictive information}}
\]

这是投资研究真正关心的层级。

---

## 5.1.4 Granger 因果

如果 X 的过去在控制 Y 自己过去后仍改善 Y 预测，则：

\[
X\Rightarrow_G Y
\]

这是：

\[
\boxed{\text{predictive precedence}}
\]

不是结构因果。

---

## 5.1.5 结构因果

真正结构因果问：

\[
do(X=x)
\]

是否改变：

\[
Y
\]

需要：

- 外生冲击；
- 工具变量；
- 自然实验；
- 结构模型；

等更强识别条件。

本项目第五章主要停留在：

\[
\boxed{\text{predictive relation}}
\]

而不是结构因果识别。

---

# 5.2 未来收益的定义必须先冻结

长期研究使用沪深300全收益指数：

\[
TR_t
\]

因为长期投资者真实财富变化包含：

- 价格变化；
- 分红；
- 分红再投资。

---

## 5.2.1 State Return

在决策日：

\[
D_t
\]

以当日全收益指数为起点：

\[
R^{state}_{t,h}
=
\frac{TR_{E(t,h)}}{TR_{D_t}}-1
\]

这里：

\[
E(t,h)
\]

是目标月份最后一个真实交易日。

---

## 5.2.2 Execution Return

实际信号只能在下一交易日执行：

\[
N(D_t)
\]

所以：

\[
R^{exec}_{t,h}
=
\frac{TR_{E(t,h)}}{TR_{N(D_t)}}-1
\]

---

## 5.2.3 为什么两种 return 都需要

State return 测：

> 信号状态本身与未来回报的关系。

Execution return 测：

> 信号如果真实执行，收益是否仍存在。

二者差异是：

\[
\boxed{\text{timing realism}}
\]

---

# 5.3 Arithmetic Return 与 Log Return

简单收益：

\[
R_{t,h}
=
\frac{P_{t+h}}{P_t}-1
\]

对数收益：

\[
r_{t,h}
=
\ln\frac{P_{t+h}}{P_t}
\]

关系：

\[
r=\ln(1+R)
\]

小收益时：

\[
r\approx R
\]

---

## 5.3.1 为什么长期目标通常保留简单收益

因为投资者更容易理解：

```text
未来5年总收益 +80%
```

而不是：

```text
log return = 0.588
```

---

## 5.3.2 为什么时间序列推导常用 log return

对数收益具有可加性：

\[
r_{t,h}
=
\sum_{j=1}^{h}r_{t+j}
\]

这使重叠收益的自相关结构更容易推导。

---

# 5.4 Pearson 相关到底测什么

给定：

\[
(X_i,Y_i),\quad i=1,\dots,n
\]

Pearson correlation：

\[
r
=
\frac{
\sum_i(X_i-\bar X)(Y_i-\bar Y)
}{
\sqrt{
\sum_i(X_i-\bar X)^2
\sum_i(Y_i-\bar Y)^2
}
}
\]

满足：

\[
-1\le r\le1
\]

---

# 5.5 Pearson 相关只测线性关系

如果：

\[
Y=X^2
\]

且 X 对称分布，可能：

\[
Corr(X,Y)\approx0
\]

但 X 与 Y 明显有关系。

所以：

\[
r=0
\]

只表示：

\[
\boxed{\text{没有线性相关}}
\]

不是：

\[
\boxed{\text{没有任何关系}}
\]

---

# 5.6 Pearson 的常规显著性检验

在理想独立、近似联合正态条件下：

\[
t
=
r\sqrt{
\frac{n-2}{1-r^2}
}
\]

自由度：

\[
n-2
\]

原假设：

\[
H_0:\rho=0
\]

---

# 5.7 P 值的严格解释

若：

\[
H_0
\]

为真，p 值是：

> 得到当前统计量或更极端统计量的概率。

它不是：

> 原假设为真的概率。

即：

\[
p\neq P(H_0|\text{data})
\]

---

# 5.8 Effect Size 与 Significance

样本越大：

\[
SE\downarrow
\]

所以很小的：

\[
r
\]

也可能显著。

因此必须同时报告：

\[
\boxed{
r
+
CI
+
p
+
n
}
\]

对投资决策而言：

\[
\boxed{\text{effect size 通常比 p 值更重要}}
\]

---

# 5.9 时间序列里“普通 Pearson p 值”为什么危险

常规 t 检验隐含：

\[
(X_t,Y_t)
\]

之间近似独立。

但宏观因子通常：

\[
Corr(X_t,X_{t-1})>0
\]

未来收益也可能高度重叠。

这意味着：

\[
n_{\text{nominal}}
>
n_{\text{effective}}
\]

所以普通 p 值容易过小。

---

# 5.10 Spearman Rank Correlation

Spearman correlation：

\[
\rho_S
=
Corr(Rank(X),Rank(Y))
\]

它测：

\[
\boxed{\text{单调关系}}
\]

而不是线性关系。

---

## 5.10.1 为什么本项目值得同时看 Spearman

第三章很多 predictor 已经做 percentile transform。

如果未来收益与因子关系：

- 单调；
- 非线性；
- 有极端值；

Spearman 可以作为稳健性检查。

如果 Pearson 和 Spearman 方向一致，证据更稳。

---

# 5.11 滞后扫描到底在扫什么

可以定义：

\[
\rho(h)
=
Corr(
X_t,
R_{t+h,horizon}
)
\]

其中：

\[
h=0,1,\dots,L
\]

它考察：

> 固定今天的 X，未来收益窗口向后平移以后，关系怎样变化？

---

# 5.12 “峰值 lag”不能机械解释成真实经济领先期

假设最大相关发生在：

\[
h=6
\]

不能直接说：

> X 真正领先股市 6 个月。

因为多个 h 的估计高度相关，而且我们进行了：

\[
L+1
\]

次比较。

最大值：

\[
\max_h|r(h)|
\]

天然有：

\[
\boxed{\text{multiple-testing selection bias}}
\]

---

# 5.13 Lag Scan 更合理的用途

主要看形态：

### 尖峰

可能提示特定延迟机制。

### 平台

说明关系在多个 horizon 都类似。

### 单调增强

更像长期均值回归或慢传导。

### 符号翻转

说明关系不稳定或存在周期阶段。

---

# 5.14 Lag Scan 应增加置信区间

理想做法不是只画：

\[
r(h)
\]

还画：

\[
CI_h
\]

而且由于不同 lag 同时检验，可使用：

- bootstrap simultaneous bands；
- FDR；
- Bonferroni 作为保守参考。

---

# 5.15 Granger 因果的核心思想

考虑：

\[
Y_t
\]

的自回归模型：

\[
Y_t
=
c+
\sum_{i=1}^{L}
a_iY_{t-i}
+
\varepsilon_t
\]

加入 X 的过去：

\[
Y_t
=
c+
\sum_{i=1}^{L}
a_iY_{t-i}
+
\sum_{i=1}^{L}
b_iX_{t-i}
+
\varepsilon_t
\]

检验：

\[
H_0:
b_1=\dots=b_L=0
\]

如果拒绝：

\[
X\Rightarrow_GY
\]

---

# 5.16 F Test 的数学

受限模型残差平方和：

\[
RSS_R
\]

不受限：

\[
RSS_U
\]

约束个数：

\[
q=L
\]

F 统计量：

\[
F
=
\frac{
(RSS_R-RSS_U)/q
}{
RSS_U/(n-k_U)
}
\]

其中：

\[
k_U
\]

是不受限模型参数数。

---

# 5.17 Granger 不是“哲学因果”

可能存在：

\[
Z_{t-1}\rightarrow X_t
\]

和：

\[
Z_{t-1}\rightarrow Y_t
\]

于是 X 能预测 Y，但 X 不是结构原因。

因此：

\[
\boxed{
Granger\ causality
=
incremental\ time-series\ predictability
}
\]

---

# 5.18 Granger 还依赖 Stationarity

经典 VAR Granger 通常要求序列平稳，或者正确处理：

- trend；
- unit root；
- cointegration。

若变量是：

\[
I(1)
\]

直接水平 VAR 可能产生伪关系。

所以 Granger 之前应明确：

\[
IntegrationOrder
\]

---

# 5.19 Lag Order 为什么不能只挑最小 p 值

如果：

```text
L = 1,2,3,4,5,6
```

全部跑，再只报：

\[
\min p_L
\]

就进行了隐性多重搜索。

合理办法：

### AIC

\[
AIC=-2\ln L+2k
\]

### BIC

\[
BIC=-2\ln L+k\ln n
\]

### HQIC

介于二者。

先用信息准则选 lag，再检验，更规范。

---

# 5.20 为什么 BIC 在小样本常更保守

BIC 的复杂度惩罚：

\[
k\ln n
\]

通常大于 AIC 的：

\[
2k
\]

所以更不容易选择过多 lag。

223 个月的小样本中，这是一个重要考虑。

---

# 5.21 Granger 的 OOS 版本更重要

In-sample Granger 显著不代表 OOS 有用。

真正投资问题是：

\[
ForecastError_{withX}
<
ForecastError_{withoutX}
\]

所以后续 benchmark ladder 应把 Granger 视为：

\[
\boxed{\text{diagnostic evidence}}
\]

而不是模型准入的最终条件。

---

# 5.22 短期收益也并不一定“近似独立”

原稿把 1–24 月归为常规统计区间，需要更谨慎。

例如 12 个月未来收益：

\[
R_{t,12}
\]

和：

\[
R_{t+1,12}
\]

仍然共享 11 个月路径。

所以只要 horizon：

\[
h>1
\]

就存在 overlap。

因此：

\[
\boxed{
\text{重叠问题不是 36 月以后才突然出现}
}
\]

只是 horizon 越长越严重。

---

# 5.23 重叠收益的数学结构

用 log return：

\[
r^{(h)}_t
=
\sum_{j=1}^{h}u_{t+j}
\]

如果单期收益：

\[
u_t
\]

独立同分布，方差：

\[
Var(u_t)=\sigma^2
\]

则：

\[
Var(r_t^{(h)})=h\sigma^2
\]

相邻 h 期收益：

\[
r_t^{(h)}
\]

和：

\[
r_{t+1}^{(h)}
\]

共享：

\[
h-1
\]

个单期收益。

因此：

\[
Cov(
r_t^{(h)},
r_{t+1}^{(h)}
)
=
(h-1)\sigma^2
\]

于是：

\[
Corr
=
\frac{h-1}{h}
\]

---

# 5.24 为什么 \((h-1)/h\) 只是教学近似

这个公式依赖：

\[
u_t
\]

独立、同方差。

现实收益存在：

- volatility clustering；
- regime；
- autocorrelation；
- dividends；
- monthly trading calendar effects。

因此：

\[
\boxed{
Corr\approx(h-1)/h
}
\]

只能用于说明 overlap 有多严重，不能当成实际样本相关系数。

---

# 5.25 Overlapping Return 产生什么统计后果

预测回归：

\[
R_{t,h}
=
\alpha+\beta X_t+\varepsilon_{t,h}
\]

即使单期创新独立，重叠 h 期 return 会让：

\[
\varepsilon_{t,h}
\]

近似具有：

\[
MA(h-1)
\]

结构。

所以 OLS 系数本身可能仍有意义，但普通 OLS standard error 错了。

---

# 5.26 Hansen–Hodrick Standard Error

Hansen–Hodrick 专门针对重叠多期收益。

思想是允许：

\[
Cov(\varepsilon_t,\varepsilon_{t-k})
\neq0
\]

直到：

\[
k=h-1
\]

因此构造 long-run covariance matrix。

这是长期预测回归的经典工具之一。

---

# 5.27 Newey–West / HAC

更一般的 HAC：

\[
\widehat{\Omega}
=
\Gamma_0+
\sum_{k=1}^{L}
w_k
(\Gamma_k+\Gamma_k')
\]

Bartlett 权重：

\[
w_k
=
1-\frac{k}{L+1}
\]

HAC 允许：

- heteroskedasticity；
- autocorrelation。

---

# 5.28 Hansen–Hodrick 与 Newey–West 的区别

Hansen–Hodrick：

- 专门针对 overlap；
- 常用 equal weights 到 \(h-1\)。

Newey–West：

- 更一般；
- 用递减 kernel weight；
- 保证 PSD covariance estimate。

本项目若后续做 predictive regression，建议至少报告：

\[
\boxed{
OLS\ coefficient
+
HAC\ standard\ error
}
\]

---

# 5.29 为什么 Block Bootstrap 仍然有价值

HAC 依赖 asymptotic approximation。

长期 120m 样本非常小，且 predictor 可能 persistent。

Bootstrap 可以更直接估计有限样本不确定性。

因此：

\[
\boxed{
HAC
+
BlockBootstrap
+
Non-overlap
}
\]

是互补的，而不是互斥。

---

# 5.30 有效样本量是什么

如果序列自相关：

\[
\rho_k
\]

均值的近似有效样本量：

\[
n_{eff}
\approx
\frac{
n
}{
1+2\sum_{k=1}^{\infty}\rho_k
}
\]

这是比简单：

\[
n/h
\]

更一般的公式思想。

---

# 5.31 为什么 \(n/h\) 只能作为直觉量级

对于 h 个月 overlap return，如果极端简化认为：

> 每 h 个月才提供一个新的独立窗口，

则：

\[
n_{eff}\approx n/h
\]

如果把 h 用年表示：

\[
n_{eff}
\approx
\frac{n}{h/12}
\]

这是非常粗略的“独立窗口数量”。

不能把它当严格 degrees of freedom。

真实 \(n_{eff}\) 取决于：

- predictor autocorrelation；
- return innovation；
- overlap；
- regression residual。

---

# 5.32 为什么 120m 结果必须非常谨慎

即使 nominal：

\[
n=103
\]

真正独立的 10 年市场阶段非常少。

中国 A 股 2008—2026 本身只覆盖：

- 全球金融危机后；
- 2015 杠杆牛熊；
- 2018 去杠杆；
- 疫情；
- 2021—2024 下行；
- 2025—2026。

所以 10 年结果实际上高度依赖少数宏观 regime。

---

# 5.33 Non-overlapping Sample Check

如果 horizon：

\[
h=60
\]

取起点：

\[
t_0,t_0+60,t_0+120,...
\]

可以消除机械 overlap。

优点：

\[
\boxed{\text{简单、直观}}
\]

缺点：

\[
\boxed{\text{样本极少}}
\]

---

# 5.34 为什么 Non-overlap 更适合看方向而不是显著性

如果只剩：

\[
3\sim5
\]

个窗口，任何 p 值都意义有限。

它更适合：

> 是否所有独立窗口都大致保持同方向？

这是：

\[
\boxed{\text{sanity check}}
\]

---

# 5.35 Block Bootstrap 的基本思想

原序列：

\[
Z_1,\dots,Z_n
\]

切成长度：

\[
L
\]

的块。

每次有放回抽取 block，拼成：

\[
Z_1^*,...,Z_n^*
\]

计算统计量：

\[
T^*
\]

重复 B 次得到：

\[
\{T_1^*,...,T_B^*\}
\]

---

# 5.36 为什么 Block 能保留时间结构

普通 bootstrap 抽单点：

\[
Z_3,Z_{100},Z_{20},...
\]

会打碎相邻依赖。

Block：

\[
(Z_{20},...,Z_{20+L-1})
\]

整段保留，所以短期自相关仍存在。

---

# 5.37 Block Bootstrap 有哪些类型

## Moving Block Bootstrap

所有长度 L 的连续块都可作为抽样单位。

## Non-overlapping Block Bootstrap

先固定分块。

## Circular Block Bootstrap

把序列首尾连成环，减少边界问题。

## Stationary Bootstrap

block 长度随机，通常几何分布。

这些方法目的相同，但有限样本性质不同。

---

# 5.38 Block Length 是一个统计参数

L 太小：

\[
\text{依赖结构保留不足}
\]

L 太大：

\[
\text{独立块数量太少}
\]

所以：

\[
\boxed{
BiasVarianceTradeoff
}
\]

再次出现。

---

# 5.39 为什么固定 24 个月不能对所有 horizon 都视为天然最优

36m、60m、120m 的 overlap 长度完全不同。

对 120m：

\[
L=24
\]

可能仍然远小于主要依赖长度。

因此更严谨做法是：

```text
12
24
36
60
120
```

进行敏感性。

如果结论只在 L=24 成立，就不能说结果稳健。

---

# 5.40 Bootstrap CI 怎样解释

如果 95% CI：

\[
[-0.80,-0.41]
\]

不含 0，可以说：

> 在当前 bootstrap 设计下，相关为负的证据较强。

不能说：

> 有 95% 概率真实相关就在这个区间。

频率学派 CI 的严格解释仍然是重复抽样覆盖率。

---

# 5.41 Percentile Bootstrap CI 的局限

直接取：

\[
2.5\%,97.5\%
\]

是 percentile CI。

简单，但可能有：

- bias；
- skewness；

问题。

更高级方法：

- BCa bootstrap；
- studentized bootstrap。

样本很小时可考虑。

---

# 5.42 Predictor Persistence 会带来额外问题

估值、利率、宏观因子通常高度 persistent：

\[
X_t=\rho X_{t-1}+u_t
\]

其中：

\[
\rho\approx1
\]

预测回归：

\[
R_{t,h}
=
\alpha+\beta X_t+\varepsilon_t
\]

在小样本中可能出现：

\[
\boxed{\text{persistent predictor bias}}
\]

---

# 5.43 Stambaugh Bias 的思想

如果 predictor innovation：

\[
u_t
\]

与 return innovation：

\[
\varepsilon_t
\]

相关，且 predictor 高度持久，OLS 的：

\[
\hat\beta
\]

存在有限样本偏差。

这在估值预测研究中非常经典。

因此仅看 OLS slope 和 ordinary t-stat 可能过于乐观。

---

# 5.44 为什么估值长期预测尤其需要这种警惕

PE/EYG 本身高度持久。

长期收益也高度 overlap。

所以同时存在：

\[
\boxed{
\text{overlap}
+
\text{predictor persistence}
+
\text{small effective sample}
}
\]

因此“r=-0.76”很强，但统计不确定性必须被严肃处理。

# 5.45 一个更稳健的长期证据链

对于估值，理想报告：

### 1. Raw correlation

\[
r
\]

### 2. Spearman

单调性。

### 3. HAC predictive regression

\[

\]

### 4. Block bootstrap CI

有限样本。

### 5. Non-overlap sign check

独立阶段方向。

### 6. Walk-forward OOS

真正预测价值。

如果六条大体一致，才是强证据。

# 5.46 Multiple Horizons 也是多重检验

同时测试：

```text
36m
60m
120m
```

已经是三个 hypothesis。

再乘：

```text

```

就是：

\[
24
\]

个长期相关测试。

如果再加多个 lag：

\[
\text{tests}\uparrow
\]

假阳性概率自然上升。

# 5.47 Family-wise Error

若每个独立检验：

\[
\alpha=0.05
\]

做：

\[
m
\]

次，至少一个假阳性的概率：

\[
1-(1-\alpha)^m
\]

例如：

\[
m=20
\]

约：

\[
64\%
\]

所以不能只看零散的 \(p<0.05\)。

---

# 5.48 多重检验的处理

### Bonferroni

阈值：

\[
\alpha/m
\]

很保守。

### Holm

逐步 Bonferroni。

### Benjamini–Hochberg

控制 FDR。

### Pre-registration / Hierarchy

更适合本项目：

> 先验上把估值设为核心 hypothesis，其他模块作为 secondary evidence。

这比事后挑显著结果更可信。

---

# 5.49 ADF：单位根到底是什么

AR(1)：

\[
X_t=\rho X_{t-1}+\epsilon_t
\]

若：

\[
|\rho|<1
\]

序列均值回归。

若：

\[
\rho=1
\]

则：

\[
X_t=X_{t-1}+\epsilon_t
\]

是随机游走。

---

# 5.50 I(0) 与 I(1)

若 X 本身平稳：

\[
X_t\sim I(0)
\]

若 X 不平稳，但：

\[
\Delta X_t
\]

平稳：

\[
X_t\sim I(1)
\]

---

# 5.51 ADF 回归

\[
\Delta X_t
=
\alpha
+
\beta t
+
\gamma X_{t-1}
+
\sum_{i=1}^{k}
\delta_i\Delta X_{t-i}
+
\epsilon_t
\]

原假设：

\[
H_0:\gamma=0
\]

即存在单位根。

---

# 5.52 ADF 的三个关键设置

### Constant

是否含截距。

### Trend

是否含 deterministic trend。

### Lag Length

控制残差自相关。

错误规格可能改变结论。

---

# 5.53 为什么 ADF “不拒绝”不等于“已经证明 I(1)”

ADF 的：

\[
H_0=\text{unit root}
\]

如果：

\[
p>0.05
\]

只能说：

> 证据不足以拒绝单位根。

不能说：

> 已经证明一定 I(1)。

还应结合：

- PP test；
- KPSS；
- 差分 ADF；
- 图形。

---

# 5.54 KPSS 为什么很有价值

KPSS 的原假设相反：

\[
H_0=\text{stationary}
\]

所以：

- ADF 不拒绝单位根；
- KPSS 拒绝平稳；

两者一致时，I(1) 证据更强。

---

# 5.55 Structural Break 会让 ADF 误判

如果真实序列是围绕变化中枢平稳：

\[
\mu_t
\]

发生断点，ADF 可能把它误判为单位根。

例如：

- 利率制度变化；
- M1 定义改变；
- 2015 市场制度冲击。

因此可考虑：

- Zivot–Andrews；
- breakpoint ADF。

---

# 5.56 协整究竟解决什么问题

如果：

\[
X_t\sim I(1)
\]

\[
Y_t\sim I(1)
\]

但存在：

\[
Y_t-\beta X_t
\sim I(0)
\]

则：

\[
X,Y
\]

协整。

含义：

> 两个非平稳序列虽然各自漂移，但不会无限偏离某个长期线性关系。

---

# 5.57 协整不是普通相关

两个随机游走可能：

\[
Corr(X,Y)
\]

很高，但没有协整。

协整关注：

\[
\boxed{\text{偏离是否均值回归}}
\]

而不是 contemporaneous correlation。

---

# 5.58 标准协整分析的积分阶数前提

经典 Engle–Granger / Johansen 最常见设定要求：

\[
X_t,Y_t
\]

都是：

\[
I(1)
\]

然后检验某个线性组合是否：

\[
I(0)
\]

---

# 5.59 一个必须修正的原稿解释

原项目阶段性 ADF 结果记录：

```text
log(price)  → 不拒绝单位根
log(PE)     → 拒绝单位根，I(0)
10Y rate    → 不拒绝单位根
EYG         → 拒绝单位根，I(0)
```

如果这些判定成立，那么：

\[
log(price)\sim I(1)
\]

而：

\[
log(PE)\sim I(0)
\]

以及：

\[
EYG\sim I(0)
\]

此时不能把：

```text
log(price) × log(PE)
log(price) × EYG
```

按标准“两个 I(1) 序列存在协整”的框架解释。

原因是它们的积分阶数不同。

因此原稿中：

> “价格与 PE / EYG 协整，所以存在长期均衡”

这句话需要重新验证，而不能直接作为已成立结论。

---

# 5.60 混合 I(0)/I(1) 时可以怎么做

一个常见替代框架是：

\[
\boxed{\text{ARDL / Bounds Testing}}
\]

它允许 regressors 混合：

\[
I(0)
\]

和：

\[
I(1)
\]

但要求没有：

\[
I(2)
\]

变量。

---

# 5.61 ARDL 基本形式

\[
Y_t
=
c
+
\sum_{i=1}^{p}\phi_iY_{t-i}
+
\sum_{j=0}^{q}\beta_jX_{t-j}
+
\epsilon_t
\]

可以重写为 error-correction form：

\[
\Delta Y_t
=
\lambda
(Y_{t-1}-\theta X_{t-1})
+
\sum\psi_i\Delta Y_{t-i}
+
\sum\gamma_j\Delta X_{t-j}
+
\epsilon_t
\]

---

# 5.62 ARDL Bounds Test

检验长期水平项是否联合显著。

其优势：

> 不要求所有变量都严格同阶 \(I(1)\)。

因此如果 PE 是 I(0)、价格 I(1)，ARDL 比机械 Johansen 更合适。

---

# 5.63 Johansen Test 的真正适用场景

对于：

\[
X_t
\]

是多个 \(I(1)\) 变量组成的向量，VAR：

\[
X_t=A_1X_{t-1}+\dots+A_pX_{t-p}+\epsilon_t
\]

重写为：

\[
\Delta X_t
=
\Pi X_{t-1}
+
\sum_{i=1}^{p-1}
\Gamma_i\Delta X_{t-i}
+
\epsilon_t
\]

其中：

\[
\Pi=\alpha\beta'
\]

若：

\[
rank(\Pi)=r
\]

则有：

\[
r
\]

个协整关系。

---

# 5.64 Johansen Trace Test

设 ordered eigenvalues：

\[
\hat\lambda_1\ge\dots\ge\hat\lambda_k
\]

trace statistic：

\[
Trace(r)
=
-T
\sum_{i=r+1}^{k}
\ln(1-\hat\lambda_i)
\]

检验：

\[
H_0:
rank(\Pi)\le r
\]

---

# 5.65 Johansen 结果还依赖什么

非常敏感于：

- VAR lag；
- constant / trend specification；
- sample length；
- structural break；
- small-sample bias。

所以不能只报告：

```text
trace > critical
```

而不说明模型设定。

---

# 5.66 VECM 的数学

若存在协整：

\[
\beta'X_t
\]

平稳，则：

\[
\Delta X_t
=
\alpha\beta'X_{t-1}
+
\sum_i\Gamma_i\Delta X_{t-i}
+
\epsilon_t
\]

其中：

\[
\beta'X_{t-1}
\]

是 error-correction term。

---

# 5.67 Alpha 的含义

若价格方程：

\[
\Delta P_t
=
\alpha_PECT_{t-1}
+\dots
\]

则：

\[
\alpha_P
\]

表示价格如何响应长期偏离。

但符号不能脱离：

\[
ECT
\]

的定义方向单独解释。

如果把：

\[
ECT
\]

乘 \(-1\)，alpha 也会翻号。

所以“alpha < 0 才回归”不是无条件规则。

必须看：

\[
\boxed{\alpha\times ECT}
\]

怎样推动系统回到均衡。

---

# 5.68 Alpha 大小也不能直接翻译成“3-10 年回归速度”

若：

\[
\alpha=-0.02
\]

这是每期 error correction coefficient。

真正 half-life 取决于完整动态系统。

简单 AR(1) 近似下：

\[
HalfLife
\approx
\frac{\ln(0.5)}
{\ln(1+\alpha)}
\]

但 VECM 多变量环境更加复杂。

所以：

> “alpha 小 → 调整慢”

可以说。

但：

> “alpha=0.02 → 一定 5 年回归”

不能直接说。

---

# 5.69 Price 与 PE 的一个更深层定义关系

PE：

\[
PE_t
=
\frac{P_t}{E_t}
\]

所以：

\[
\log PE_t
=
\log P_t-\log E_t
\]

因此 price 与 PE 不是完全独立的两个经济序列。

它们共享：

\[
P_t
\]

这会产生机械相关。

如果要研究长期基本面均衡，更自然的系统可能是：

\[
\log P_t
\]

与：

\[
\log Earnings_t
\]

或 dividend / book value。

然后：

\[
\log P-\log E
\]

就是估值 spread。

---

# 5.70 为什么“价格和 PE 协整”概念上也需要谨慎

因为 PE 已经包含 price。

它不像：

```text
price × independent macro fundamental
```

那样完全独立。

因此即使统计上出现长期关系，也需要区分：

\[
\boxed{
\text{定义共用成分}
}
\]

与：

\[
\boxed{
\text{真正经济均衡约束}
}
\]

---

# 5.71 EYG 同样含有 PE

\[
EYG_t
=
\frac{1}{PE_t}
-
Y10_t
\]

所以：

\[
EYG
\]

也不是与 price 完全独立的外部基本面。

这也是为什么它对未来收益有效并不令人意外，但解释必须避免循环论证。

---

# 5.72 更合适的长期均衡候选

可以考虑：

### Price – Earnings

\[
\log P_t
\quad vs\quad
\log E_t
\]

### Price – Book

\[
\log P_t
\quad vs\quad
\log B_t
\]

### Dividend – Price

Campbell–Shiller 框架。

### Earnings Yield – Real Rate

估值 vs discount-rate equilibrium。

这些结构更接近资产定价理论。

---

# 5.73 Campbell–Shiller Log-linear Identity

资产定价中可近似：

\[
p_t-d_t
\approx
\sum_{j=1}^{\infty}
\rho^{j-1}
E_t(
\Delta d_{t+j}-r_{t+j}
)
\]

直觉：

> 高价格-股息比要么意味着未来现金流增长更高，要么意味着未来收益更低。

这给“估值预测长期收益”一个成熟理论基础。

---

# 5.74 为什么估值对长期收益负相关具有经济逻辑

初始价格高意味着：

\[
\frac{E}{P}\downarrow
\]

若长期盈利增长没有永久同步提高，则未来可实现收益下降。

所以：

\[
ValuationHigh_t
\Rightarrow
E(R_{t,h})\downarrow
\]

这是均值回归 / discount-rate channel。

---

# 5.75 但估值预测并不是无风险套利

高估值可能持续多年。

即：

\[
E(R_{long}|Valuation)
\]

有关系，不等于：

\[
R_{next\ month}
\]

可预测。

所以估值是：

\[
\boxed{\text{slow-moving expected-return signal}}
\]

而不是短期价格方向信号。

---

# 5.76 如何重新理解原阶段性“估值最强”结果

原结果记录：

\[
r_{36}\approx-0.585
\]

\[
r_{60}\approx-0.669
\]

\[
r_{120}\approx-0.762
\]

这个形态非常值得重视：

\[
|r_h|
\uparrow
\text{ as }h\uparrow
\]

它与长期估值均值回归逻辑一致。

但证据强度必须结合：

- overlap；
- small \(n_{eff}\)；
- block length；
- persistent predictor；
- multiple testing；
- OOS。

---

# 5.77 “单调增强”为什么比单个 p 值更有信息

如果三个 horizon 都：

\[
r<0
\]

且绝对值逐步增加，这是一种：

\[
\boxed{\text{cross-horizon coherence}}
\]

它比“某一个 horizon 恰好显著”更难由随机噪声解释。

但仍应通过 bootstrap / OOS 验证。

---

# 5.78 Growth / Inflation 等部分显著该如何解释

如果：

```text

60m 不显著
120m 不显著
```

不应该说：

> Growth 可以预测长期收益。

更准确：

> 在部分 horizon 和当前样本下存在负相关，但跨期限稳定性不足。

# 5.79 M1-M2 未复现为什么很重要

先验假说：

\[
M1-M2
\Rightarrow
FutureReturn
\]

如果数据不支持，就应保留：

\[
\boxed{\text{negative result}}
\]

这能防止模型变成：

> 只保留我们想看到的规律。

---

# 5.80 Negative Result 也需要看“是否是因子压缩造成”

M1-M2 可能在单变量中有信息，但 Liquidity PCA 可能把它稀释。

所以否定时应区分：

### Hypothesis A

Liquidity module 没有预测力。

### Hypothesis B

当前 PCA representation 没提取到预测力。

两者不同。

---

# 5.81 这就是为什么需要 Baseline Ladder

应该比较：

```text
raw single variable
engineered feature
PCA factor
multi-factor model
```

如果：

\[
M1M2Gap
\]

单独有效而 PCA 无效，说明：

\[
\boxed{\text{compression loss}}
\]

而不是经济变量本身无效。

---

# 5.82 Granger 显著也不能直接写成“短期可交易”

例如：

\[
p<0.001
\]

但实际预测改善：

\[
\Delta RMSE=0.1\%
\]

可能没有经济意义。

所以应报告：

- OOS RMSE；
- MAE；
- directional accuracy；
- utility；
- transaction cost robustness。

---

# 5.83 Statistical Significance vs Economic Significance

统计显著：

\[
p<0.05
\]

经济显著：

> 信号幅度足以改变资产配置结果。

例如：

\[
\beta=-0.01
\]

即使极显著，也可能对仓位没有实际价值。

# 5.84 OOS 是第五章之后所有结论的最终门槛

In-sample 只能说：

> 过去样本里存在关系。

真正研究目标：

\[
P(R_{t,t+h}|X_t)
\]

需要问：

> 在历史未知未来的情况下，这种关系能否重复出现？

所以：

\[
\boxed{

>
InSample
}
\]

# 5.85 Walk-forward 的基本结构

训练集：

\[

\]

预测：

\[

\]

然后扩展：

\[

\]

预测：

\[

\]

这是：

\[
\boxed{\text{expanding-window walk-forward}}
\]

# 5.86 为什么随机 train/test split 不适合时间序列

随机打乱会让训练集包含：

\[

\]

而测试：

\[

这破坏：

\[
\boxed{\text{信息时间顺序}}
\]

所以必须 time split。

# 5.87 长期 horizon 的 Walk-forward 更困难

\boxed{\text{label availability}}

问题。

如果在 2015 年训练模型，不能使用：

```text

```

因为它到 2020 才完成。

# 5.88 Target PIT 也是 PIT

\[

\]

只有满足：

的历史标签可以进入训练。

\[
\boxed{\text{label-time PIT}}
\]

与 predictor PIT 同样重要。

# 5.89 Long-horizon Model 的真正训练样本更少

\[

\]

个。

# 5.91 当前“估值最强”的正确表述

更严谨。

# 5.92 当前宏观状态的正确表述

如果 MacroState 在某些 horizon 显著，但并非所有 horizon 稳定：

应说：

> 综合宏观状态可能含有期限依赖的预测信息，但稳定性弱于估值，不能单独作为长期主锚。

# 5.93 为什么宏观变量可能短期弱、长期也弱

市场价格本身是 forward-looking：

\[

- 高频数据；

定价。

所以：

\[
\boxed{

\neq
\text{宏观变量有额外收益预测力}
}

# 5.97 本章最常见的二十个误解

1. “相关显著就是因果。”——错误。
2. “Granger causality 就是真因果。”——错误。
3. “p 越小，经济效果越大。”——错误。
4. “短中期收益就是独立样本。”——错误。
5. “36m 相邻收益相关一定等于 35/36。”——只是简化条件下近似。
6. “\(n/h\) 就是真实自由度。”——只是直觉量级。
7. “普通 OLS p 值可用于重叠收益。”——通常不可靠。
8. “block length=24 是普适最优。”——错误。
9. “bootstrap CI 不含 0 就万事大吉。”——仍有模型选择和多重检验。
10. “最小 lag p 值就是最优 lag。”——有选择偏差。
11. “ADF p>0.05 就证明 I(1)。”——错误。
12. “两个序列只要长期相关就协整。”——错误。
13. “一个 I(0) 和一个 I(1) 可以直接按标准 Johansen 协整解释。”——错误。
14. “VECM alpha 小就能直接换算为几年回归。”——错误。
15. “价格与 PE 是完全独立变量。”——错误，PE 含 price。
16. “估值相关越强就一定可交易。”——错误。
17. “宏观因子不显著就说明宏观不重要。”——错误。
18. “M1-M2 因子不显著就证明单变量也没用。”——错误。
19. “In-sample 显著等于 OOS 可预测。”——错误。
20. “120m 有 103 个标签就等于有 103 个独立十年样本。”——错误。

# 5.101 本章最终结论

第五章真正建立的不是一句：

> “估值显著。”

而是一套证据判断框架：

\[
\boxed{
\text{Association}
\rightarrow
\text{Temporal precedence}
\rightarrow
\text{Dependence-robust inference}
\rightarrow
\text{Long-run consistency}
\rightarrow
\text{OOS validation}
}
\]

目前阶段性结果最值得重视的发现仍然是：

\[
\boxed{
\text{估值与未来长期收益存在强而稳定的负向关系}
}
\]

但更严谨的表述必须同时承认：

- 长周期收益高度重叠；
- 120m 实际独立 regime 极少；
- predictor 高持久；
- block length 有敏感性；
- 多重检验存在；
- 部分原协整解释需要按 integration order 重新规范。

因此第五章把研究从：

\[
\text{“看起来有关”}
\]

推进到：

\[
\text{“这种关系在什么统计条件下仍然可信”}
\]
