# 8.1 第 1 章：我们到底在测量什么

第一章建立的是“经济状态测量系统”。

真实经济状态不可直接完整观测，可以抽象为：

\[
S_t=
\begin{bmatrix}
Growth_t\\
Inflation_t\\
Liquidity_t\\
Credit_t\\
Rates_t\\
Valuation_t\\
Household_t\\
Risk_t
\end{bmatrix}
\]

而实际数据：

\[
X_{j,t}
=
f_j(S_t)+\varepsilon_{j,t}
\]

只是对潜在状态的带噪声测量。

所以第一章最重要的认识不是：

> “我们收集了 84 个变量。”

而是：

\[
\boxed{
\text{每个变量都必须有统计定义、经济含义和可检验假说}
}
\]

---

# 8.2 第 2 章：历史当时究竟知道什么

第二章建立：

\[
\boxed{\text{PIT information set}}
\]

对每条数据：

\[
available\_date\le decision\_date
\]

才允许进入历史状态。

PIT 的本质是：

\[
X_t^{PIT}
=
\arg\max_{i:A_i\le D_t}A_i
\]

即 as-of join。

同时处理：

- vintage；
- definition regime；
- freshness；
- missingness；
- revised history；
- event persistence；
- coverage gate。

这一章决定：

\[
\boxed{
\text{回测是否有资格被称为历史模拟}
}
\]

---

# 8.3 第 3 章：当前值在自己的历史里处于哪里

第三章把：

\[
X_{j,t}
\]

转换为：

\[
Z_{j,t}
\]

主要使用 PIT-safe expanding percentile：

\[
P_{j,t}
=
\hat F_{j,t}(X_{j,t})
\]

\[
Z_{j,t}
=
2P_{j,t}-1
\]

其含义是：

> 当前值在截至当时的可比历史里处于什么位置？

这解决的是：

\[
\boxed{\text{scale comparability}}
\]

但不制造新经济信息，也不解决因果和共线性。

---

# 8.4 第 4 章：多个变量共同代表什么经济状态

第四章用经济先验先分模块，再做 PCA。

PCA：

\[
\max_{w'w=1}
w'\Sigma w
\]

得到：

\[
\Sigma w=\lambda w
\]

把多个相关变量压缩为少数共同变化方向。

关键不是“让机器自己定义经济”，而是：

\[
\boxed{
\text{经济学定义模块，统计学负责压缩}
}
\]

最后形成：

- Growth；
- Inflation；
- Liquidity；
- Credit；
- Valuation；
- Rates；
- Household；
- Risk。

需要始终记住：

\[
\boxed{
PCA\ factor
\neq
真实因果因子
}
\]

# 8.5 第 5 章：这些状态与未来收益到底有没有关系

第五章从：

\[
P(X)
\]

进入：

\[
P(Y_{t+h}\mid X_t)

依次研究：

- Pearson / Spearman；
- lag scan；
- Granger；
- overlapping return；
- HAC；
- block bootstrap；
- ADF / KPSS；
- 协整 / ARDL；
- walk-forward。

真正的核心问题是：

\[
\boxed{
\text{当前状态是否提供对未来收益的增量预测信息？}
}
\]

# 8.8 证据等级：不同结论到底“有多确定”

这是最终章最重要的新框架。

所有研究结果分成五层。

## Level 1：Data Fact

例如：

```text
2026-07 valuation factor = 某历史高位
```

这是数据层事实。

---

## Level 2：Descriptive Statistical Pattern

例如：

```text
便宜桶的历史36m中位收益高于贵桶
```

这是样本描述。

---

## Level 3：Predictive Evidence

例如：

```text
Valuation 在 walk-forward / bootstrap 中保持负向长期关系
```

这是预测证据。

---

## Level 4：Candidate Decision Rule

例如：

```text
Compass 高 → 降低股票暴露
```

这是规则假说。

---

## Level 5：Prospective Live Evidence

规则冻结后未来真实月份持续有效。

这是最强证据。

当前项目主要达到：

\[
\boxed{
Level\ 3\sim4
}
\]

而不是永久性的 Level 5。

---

# 8.9 关键发现 1：估值是目前最强的长期预期收益锚

这是当前研究最稳健的核心发现。

长期 horizon 上：

\[
Corr(
Valuation_t,
R_{t,t+h}
)<0
\]

且绝对值随 horizon 增大。

阶段性结果约：

\[
r_{36}\approx-0.59
\]

\[
r_{60}\approx-0.67
\]

\[
r_{120}\approx-0.76
\]

这与：

\[
\boxed{\text{长期估值均值回归}}
\]

的资产定价逻辑一致。

---

# 8.10 为什么估值长期有预测力在理论上合理

股票价格可以概念化为：

\[
P_t
=
E_t
\left[
\sum_{k=1}^{\infty}
\frac{CF_{t+k}}
{(1+r_{t+k})^k}
\right]
\]

当投资者在：

\[
P_t
\]

非常高的起点买入，在未来现金流没有永久等比例提高的条件下，未来 expected return 往往较低。

所以：

\[
\boxed{
\text{valuation is closer to an expected-return state variable}
}
\]

---

# 8.11 条件分布进一步支持这个结论

阶段性结果显示：

```text
36m annualized median
便宜  +11.6%
中性   +6.1%
昂贵   -3.0%
```

并且多 horizon 基本保持：

\[
Cheap>Mid>Expensive
\]

这是比单一相关系数更直观的：

\[
\boxed{\text{distributional monotonicity}}
\]

---

# 8.12 “贵桶 54% 亏损”应该怎样正式表述

不应写：

> 当前贵时未来三年有 54% 概率亏损。

更严格：

> 在当前历史样本中，被判定为类似高估值状态的历史决策月份里，36 个月累计收益为负的经验比例约为 54%。

因为：

\[
\hat p
\neq
p_{true,today}
\]

未来 regime 仍可能变化。

---

# 8.13 对“估值长期均衡”的结论必须修正

原稿使用：

```text
log(price)
log(PE)
EYG
10Y
```

进行 ADF / Johansen / VECM，并把结果概括成：

> 价格与估值存在长期协整。

但第五章进一步指出：

如果：

\[
log(price)\sim I(1)
\]

而：

\[
log(PE)\sim I(0)
\]

或：

\[
EYG\sim I(0)
\]

就不能直接用标准 Johansen：

\[
I(1)+I(1)\rightarrow cointegration
\]

的框架解释。

因此最终章更准确的结论是：

\[
\boxed{
\text{估值存在明显长期均值回归/长期约束证据，但标准协整结论需要按 integration order 重新规范验证}
}
\]

对于混合：

\[
I(0)/I(1)
\]

系统，更适合进一步使用：

\[
\boxed{\text{ARDL / Bounds framework}}
\]

---

# 8.14 这不会推翻估值主结论

因为估值主结论并不只依赖协整。

证据仍包括：

1. 长期 correlation；
2. conditional distribution monotonicity；
3. block bootstrap；
4. OOS benchmark improvement；
5. 投资起点的资产定价逻辑。

所以协整是：

\[
\boxed{\text{辅助证据}}
\]

而不是唯一支柱。

---

# 8.15 关键发现 2：宏观状态可能提供增量，但证据弱于估值

单独：

- Rates；
- Liquidity；
- Credit；

加入估值后，增量不稳定。

但更综合的 macro block 在阶段性 Ladder 中改善 OOS RMSE。

这表明：

\[
\boxed{
\text{宏观信息更可能以组合状态形式有用}
}
\]

而不是依靠一个“神指标”。

---

# 8.16 为什么这在经济学上合理

真实经济系统：

\[
Growth
\leftrightarrow
Inflation
\leftrightarrow
Credit
\leftrightarrow
Rates
\leftrightarrow
Risk
\]

是联动的。

单个变量：

\[
X_j
\]

只测其中一个投影。

因此：

\[
\boxed{
\text{joint state}
}
\]

可能比单变量稳定。

---

# 8.17 但“宏观组合有效”目前只能叫候选结论

Model4 改善可能受到：

- 样本长度；
- model selection；
- parameter count；
- regime concentration；
- predictor overlap；

影响。

所以最终应写：

> 宏观组合在当前历史 walk-forward 评估中显示出估值之外的候选增量，并在多个子样本中保持同方向，但其稳定性仍明显弱于估值锚，需要未来 live OOS 持续验证。

---

# 8.18 PIT 滞后两期的证据也需要重新定位

原稿：

> “滞后两期 Sharpe 更好，所以 PIT 偏误可接受。”

完善后必须改成：

\[
\boxed{
\text{lag-2 test 是 timing-delay stress test，不是真正 vintage reconstruction}
}
\]

它说明：

> 策略不依赖精确的宏观发布时间。

但不能单独证明：

> revised-history bias 已完全排除。

真正 PIT 安全主要来自第二章的数据治理。

---

# 8.19 关键发现 3：当前规则的主要价值更接近风险控制，而不是超额收益

阶段性历史结果：

```text

CAGR 4.09%

MDD -23.4%

100% Equity
CAGR 4.65%

```

最明显的特征是：

\[
\boxed{
\text{lower risk}
}
\]

而不是：

\[
\boxed{
\text{higher absolute return}
}
\]

# 8.20 “0.56pp 保费”的正确含义

策略牺牲：

\[
0.56pp/year
\]

历史 CAGR，换来：

\[
Vol\downarrow
\]

和：

\[
MDD\downarrow
\]

这可以理解成：

\[
\boxed{\text{realized insurance premium}}
\]

但只是：

> 当前历史样本中的 realised trade-off。

不是未来固定价格。

# 8.21 为什么风险控制有真实经济价值

投资者效用：

\[
U(W)
\]

通常风险厌恶：

\[
U''(W)<0
\]

所以同样长期财富期望下，降低：

- volatility；
- drawdown；
- ruin risk；

具有真实价值。

---

# 8.22 但风险下降是否来自 Compass timing，还需要更强 benchmark

如果策略平均股票仓位：

\[
\bar w<100\%
\]

波动低于满仓并不奇怪。

所以必须比较：

\[
\boxed{
\text{dynamic Compass}
}
\]

与：

\[
\boxed{
\text{fixed portfolio with same average equity exposure}
}
\]

才能识别 timing value。

---

# 8.23 因此“规则仓位显著改善风险特征”的最终表述

更严谨：

> 当前历史前向评估显示，Compass 动态仓位相对满仓具有明显风险降低特征；其中多少来自动态状态识别、多少仅来自较低平均股票暴露，仍需通过同平均仓位固定组合和 volatility-matched benchmark 进一步分解。

# 8.34 当前状态的阶段性解释

基于原项目 2026-07 snapshot：

- 估值偏高；
- 信用偏弱；
- 居民信心偏低；
- 宏观综合偏冷；
- 风险/活动状态偏高。

组合意味着：

> 高估值是主要负面，偏冷宏观部分抵消“过热”风险，但并不足以把高估值转成高长期 expected return。

因此相对中性：

\[
\boxed{\text{适度低配}}
\]

逻辑是连贯的。

# 8.41 当前项目自评更适合这样写

|---|---|---|---|

| Portfolio Utility | 候选 | MDD/vol 风险改善 | fixed-risk comparator / cost / live OOS |

# 8.78 当前结论应该怎样对外表达

> 基于 2008—2026 年 PIT-safe 宏观与市场状态，本研究发现初始估值与未来 3—10 年沪深300全收益存在稳定负向关系，且条件收益分布随估值由低到高明显恶化。宏观综合状态可能在估值之外提供一定增量，但稳定性弱于估值。由此构建的 Compass 动态仓位在当前历史 walk-forward 评估中表现出较低波动和最大回撤，但其风险改善有一部分可能来自较低平均股票暴露，且历史窗口仍然有限。该系统因此应被定位为一个长期股票风险预算与状态监控框架，而不是已被证明具有永久超额收益能力的择时模型。最终有效性需要规则冻结后的 prospective live OOS 继续验证。

# 8.85 最终结语

这个项目从一个很容易被讲成“市场故事”的问题开始：

> 宏观环境和估值能不能告诉我们现在该多持还是少持股票？

最终得到的最有价值答案不是：

\[
\boxed{\text{“可以，仓位是 55%。”}}
\]

而是：

\[
\boxed{
\text{“在当前历史证据下，初始估值是最稳定的长期状态锚；宏观信息可以作为次级修正；动态仓位可能改善风险预算，但这一结论仍受样本、结构变化和规则选择影响，因此必须以 PIT、OOS、固定基准、撤回条件和未来 live track record 持续检验。”}
}
\]

这比一个单点仓位更重要。

因为真正成熟的研究系统不是：

\[
\text{永远给出确定答案}
\]

而是：

\[
\boxed{
\text{在不确定世界中，尽可能明确地知道自己知道什么、不知道什么、什么时候应该改变判断}
}
\]

这才是“宏观股市罗盘”最终应该保留下来的核心能力。
