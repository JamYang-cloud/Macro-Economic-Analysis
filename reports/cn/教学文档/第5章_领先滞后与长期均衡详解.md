## 5.0 为什么要分"短中期"和"长期"两套方法论

宏观因子与股市收益的关系**在不同时间尺度上性质完全不同**：

| 尺度 | 典型持有期 | 统计问题 | 主要发现（预告） |
|---|---|---|---|
| 短中期 | 1-24 个月 | 月度观测近似独立（自相关弱） | 估值/风险/宏观状态的 Granger 预测；收益噪声大、相关弱 |
| 长期 | 3-10 年 | **重叠样本**：相邻月起点共享路径，观测不独立 | 估值的强预测（-0.76@10 年） |

短中期可以用常规统计（月度观测 200+ 个，近似独立）；长期必须
处理"名义样本量虚高"的问题——**这是 v1.2 的核心方法论修正**。
混用一套方法（把重叠的长期收益当独立观测）会让 p 值系统性偏小
（看起来显著，实际是假阳性）。

## 5.1 短中期：相关性分析

### 5.1.1 未来收益的定义

决策月 t 的因子 X(t) 与"未来 h 个月收益"：

```
R(t, h) = Price(t+h) / Price(t) − 1
```

- Price 用沪深300 **全收益指数**（含分红再投资）——长期收益研究
  必须用全收益（分红是长期回报的重要部分，价格指数会低估）；
- h = 1/3/6/12/24 个月（短中期）；
- 决策月 t 的因子用 t 月末可得的宏观状态（PIT，第 2 章），收益是
  t 到 t+h 的实际结果——**因子在前、收益在后**，无前视。

### 5.1.2 Pearson 相关的数学

**定义**：两个序列 x、y 的线性相关：
```
r = cov(x, y) / (σx · σy) = Σ(x_i − x̄)(y_i − ȳ) / √[Σ(x_i−x̄)²·Σ(y_i−ȳ)²]
```
r ∈ [−1, 1]：+1 完全正相关（x 大时 y 也大）、−1 完全负相关、0 无
线性关系。

**显著性检验**（t 检验）：
```
t = r·√(n−2) / √(1−r²)   自由度 n−2
p 值 = t 分布双侧尾概率
```
- 原假设 H₀：ρ = 0（总体相关为 0）；
- p < 0.05 → 拒绝 H₀ → "观测到的相关不太可能来自无相关的总体"。

**p 值的正确理解**：p 是"如果真实相关为 0，观测到这么强的相关
（或更强）的概率"。p 小 ≠ 效应大——它同时受样本量影响（n 大则
p 自然小）。**看效应量（r 本身）+ 看 p**，两者都报。

**重要提醒**：相关 ≠ 因果。估值与未来收益相关，可能是"估值→收益"
（均值回归机制），也可能是"共同驱动"（第三个变量同时影响两者）。
相关性是"存在关系"的证据，机制需要经济理论支撑（第 1 章的先验
地图）+ 后面的 Granger/协整佐证。

### 5.1.3 滞后扫描（领先形态的解读）

**做法**：固定因子在 t，让收益起点滑动 h = 0..12 个月：
```
r(h) = corr( X(t), R(t+h, 3) )   h = 0, 1, ..., 12
```
r(h) 随 h 的形态有两种典型解读：
- **尖峰形态**：r(h) 在某个 h* 最大——"因子领先收益 h* 个月"
  （h*=6 表示因子对 6 个月后的收益预测力最强）；
- **单调形态**：r(h) 随 h 增大单调增强——不是"领先 N 月"，而是
  "持有期越长，关系越强"（**均值回归特征**：估值高 → 未来任意
  时点看都偏贵 → 持有越久回归越多）。

**实际结果**（Phase 5）：估值的 r(h) 随 h **单调增强**（h=1 时
−0.09 → h=12 时 −0.29）——**均值回归形态，不是领先尖峰**。这
告诉我们对估值信号的正确用法是"长期持有/长期仓位"，而不是
"预测 6 个月后的拐点"。

## 5.2 Granger 因果检验

### 5.2.1 数学：VAR 框架与 F 检验

**Granger 因果回答的问题**：X 的过去值能否**改善**对 Y 未来值的
预测（在已经用了 Y 自己的过去值之后）？这是"时序先行性"的统计
检验，不是哲学意义上的因果。

**VAR（向量自回归）框架**，检验"因子 X → 收益 Y"：
```
不受限模型：Y_t = c + Σ_{i=1..L} a_i·Y_{t-i} + Σ_{i=1..L} b_i·X_{t-i} + ε_t
受限模型：  Y_t = c + Σ_{i=1..L} a_i·Y_{t-i} + ε_t        （去掉 X 的滞后项）
```
- L = 滞后阶数（1-6 个月）；
- 比较两个模型的残差平方和（RSS）：
```
F = [(RSS_受限 − RSS_不受限) / L] / [RSS_不受限 / (n − 2L − 1)]
```
- F 统计量服从 F(L, n−2L−1) 分布 → p 值；
- 原假设 H₀：b₁ = b₂ = ... = b_L = 0（X 的滞后项无预测力）；
- p < 0.05 → 拒绝 → "X 的过去对 Y 有 Granger 因果"。

### 5.2.2 解读的边界

- **Granger 因果 = 时序先行性**：X 先变、且 X 的过去帮助预测 Y——
  这是"因果"的弱形式（必要条件非充分）；
- **不排除第三个变量**：X 和 Y 可能都被 Z 驱动（Z 先于 X）；
- **方向**：可以双向（X→Y 且 Y→X），也可能都没有；
- **滞后期选择**：L=1..6 全测，报最优（最小 p）——但注意多重
  比较（测了 6 个 L，p 最小那个有选择偏差），解读留余量。

### 5.2.3 实际结果（因子 → 未来 3 月收益，L=1-6）

| 因子 | 最优 lag | p 值 | 结论 |
|---|---|---|---|
| 估值 | 6 | <0.0001 | ✓ 显著（Granger 预测 3 月收益） |
| 风险 | 4 | <0.0001 | ✓ 显著 |
| 宏观状态 | 3 | 0.0001 | ✓ 显著 |
| 增长/通胀/流动性/信用/利率 | 1-6 | >0.05 | 不显著 |

**解读**：估值/风险/宏观状态对短期（3 个月）收益有**时序先行性**；
增长/通胀等基本面因子短期无 Granger 预测力（它们的信息在更长
尺度体现——见 5.4 长期结果）。这符合经济直觉：**市场对宏观基本
面（增长/通胀）的定价较快（公告即反应），而对估值水平/风险状态
的定价较慢（均值回归需要时间）**。

## 5.3 长期：重叠样本问题（v1.2 核心）

### 5.3.1 什么是重叠样本

研究"未来 36 个月收益"时，每个决策月 t 都有一个观测 R(t,36)——
但相邻两个观测 **R(t,36) 和 R(t+1,36) 共享 35 个月的路径**（都覆盖
t+1 到 t+35）。名义上我们有 n=187 个观测（2008-2027 的 36 月窗口），
但**这些观测高度重叠、远非独立**。

数学上：R(t,36) 与 R(t+1,36) 的相关 ≈ (36−1)/36 ≈ 97%——相邻观测
几乎重复同一个信息。

### 5.3.2 有效自由度（Boudoukh-Richardson-Whitelaw 2018）

**有效样本量** ≈ 名义样本量 / 重叠比：
```
n_eff ≈ n / (h / 12)
```
- 36 月收益：n=187 → n_eff ≈ 62；
- 60 月收益：n=163 → n_eff ≈ 33；
- 120 月收益：n=103 → n_eff ≈ **10**（10 年收益只有约 10 个独立
  观测！）。

**为什么重要**：普通 t 检验/相关性 p 值假设观测独立——重叠样本
违反这个假设，**残差自相关使标准误被低估、p 值被高估**（看起来
更显著）。120 月收益的名义 p=0.000 可能实际不显著（有效 n=10）。

### 5.3.3 处理三件套（v1.2 强制）

1. **有效自由度声明**：报告 n_eff（诚实告知"名义 187 实际约 62"）；
2. **非重叠样本检查**：每 60 个月取一个起点（0, 60, 120, 180）——
   这些起点之间无重叠（窗口 36 月 < 间隔 60 月），是"独立窗口"的
   sanity check。代价：只剩 3-4 个观测，无法做统计推断，只能看
   **方向是否一致**（如估值 60 月非重叠 r=−0.71 与原 r=−0.67 方向
   一致 ✓）；
3. **block bootstrap 置信区间**（见 5.4）——显著性判定的**主裁判**。

## 5.4 Block Bootstrap：重叠样本下的诚实显著性

### 5.4.1 Bootstrap 思想

**Bootstrap（自助法）**：不假设数据分布，直接从样本**重抽样**估计
统计量的抽样分布。做法：对 n 个观测**有放回地抽 n 个**，算统计量
（如相关系数 r），重复 B 次（如 1000 次），得到 r 的分布 → 95%
置信区间（2.5% 和 97.5% 分位）。如果 CI 不包含 0 → 显著。

### 5.4.2 普通 bootstrap 为什么在重叠样本下失败

普通 bootstrap **独立地**重抽样单个观测——它隐含假设观测独立。
但我们的 (因子, 长期收益) 配对序列有**强自相关**（重叠窗口）：
- 独立重抽样会**破坏时间结构**（把 t 的观测和 t+35 的观测随机
  配对，丢失"相邻观测高度相似"的真实性）；
- 后果：bootstrap 分布**过窄**（低估不确定性）→ CI 过紧 → 假阳性
  （把不显著的判成显著）。

### 5.4.3 块 bootstrap：保留自相关结构

**做法**：把序列切成块（块长 L 个月），**整块**有放回地重抽样：
```
原始:   [t1 t2 ... tL | tL+1 ... t2L | ...]  （切块，块长 L）
重抽样: [块3 | 块7 | 块1 | ...] 拼接成与原始等长的序列
重算 r → 记录
重复 1000 次 → r 的分布 → 95% CI
```
- **块内的观测保持相邻关系**（自相关结构保留在块内）；
- 块之间的边界是"断裂"的，但块长 L 足够大时边界效应小；
- **块长为什么 24 个月**：要超过收益的主要自相关尺度。36 月收益
  的相邻观测重叠 35 个月，自相关 ~97%——理论上块长要接近 h；
  24 个月是"经济周期片段（2 年）"与"保持足够块数"的折中（n=187
  时 24 月块 → 约 8 块/样本，1000 次重抽样块数足够）。敏感性：
  结果对块长不是特别敏感（12-36 月结论一致），报告中用 24。

### 5.4.4 实际结果（长期相关 + bootstrap CI）

| 因子 | 36 月 r [CI] | 60 月 r [CI] | 120 月 r [CI] |
|---|---|---|---|
| 估值 | −0.585 [−0.82, −0.22] ✓ | −0.669 [−0.80, −0.41] ✓ | −0.762 [−0.90, −0.53] ✓ |
| 宏观状态 | −0.375 [−0.70, −0.05] ✓ | −0.335 [−0.63, +0.01] ✗ | −0.655 [−0.80, −0.51] ✓ |
| 增长 | −0.432 [−0.65, −0.04] ✓ | −0.293 [−0.53, +0.20] ✗ | −0.067 ✗ |
| 通胀 | −0.365 [−0.70, +0.09] ✗ | −0.378 [−0.67, −0.03] ✓ | +0.156 ✗ |
| 流动性 | −0.382 [−0.59, −0.12] ✓ | −0.145 ✗ | −0.368 [−0.79, +0.09] ✗ |

**关键教学点**：
- 增长 36 月的名义 p=0.000（如果只看 p 会判"极显著"），但 bootstrap
  CI 在 60 月跨 0（[−0.53, +0.20]）→ **bootstrap 诚实淘汰了重叠
  样本造成的假显著**；
- **估值是唯一在 3/5/10 年全部 bootstrap 显著且 r 随持有期单调
  增强的因子**（−0.585 → −0.669 → −0.762）——这是整个研究最
  强的一条实证；
- 通胀 36/60 月符号不一（−0.365/+0.156@120 甚至变号）——通胀对
  长期收益的关系不稳定，不是可靠信号。

## 5.5 协整与 VECM：长期均衡关系

### 5.5.1 平稳性（ADF 检验）的数学

**平稳序列（I(0)）**：均值/方差不随时间变化、自相关只依赖滞后
长度——统计推断（t 检验/回归）要求平稳。

**单位根（I(1)）**：序列是随机游走（Δx = x_t − x_{t−1} 是平稳的）——
均值漂移、冲击永久。**对两个 I(1) 序列做回归是"伪回归"**（Granger-
Newbold：即使两者完全无关，t 统计量也会虚假地显著）。

**ADF 检验**（Augmented Dickey-Fuller）：
```
Δx_t = α + βt + γ·x_{t−1} + Σ_{i=1..k} δ_i·Δx_{t−i} + ε_t
原假设 H₀：γ = 0（有单位根，非平稳）
```
- γ < 0 且显著（p < 0.05）→ 拒绝 H₀ → 平稳（I(0)）；
- 不拒绝 → 非平稳（可能是 I(1)），再对差分检验 → 确认 I(1)。

**实际结果**：
| 序列 | 水平 ADF | 结论 |
|---|---|---|
| log(沪深300全收益) | p=0.63 不拒绝 | I(1)（价格是随机游走） |
| log(PE) | p=0.0005 拒绝 | **I(0)**（PE 倍数本身均值回归！） |
| 10Y 利率 | p=0.41 不拒绝 | I(1) |
| EYG | p=0.008 拒绝 | I(0) |

**教学点**：log(PE) 是 I(0)——**估值水平自身就是平稳的**（围绕
中枢波动），这是"估值均值回归"的最基本证据：PE 不会随机游走到
无穷，它有引力中心。

### 5.5.2 协整的定义

**协整**：两个 I(1) 序列的**线性组合是 I(0)**——它们虽然各自随机
游走，但**长期粘在一起**（均衡关系）。数学：
```
x_t, y_t 都 I(1)，但 z_t = y_t − β·x_t 是 I(0)（平稳）
→ x, y 协整，β 是长期均衡系数，z_t 是"偏离均衡的程度"
```
经济含义：价格和 PE 可以各自漂移，但**它们的长期关系稳定**——
PE 太高/太低时，价格会被"拉回"（均值回归的均衡表述）。

### 5.5.3 Johansen 检验（trace 统计量）

**Johansen 检验**：检验"协整关系的个数（秩 r）"。
- 对 VAR 系统求特征值 λ₁ ≥ λ₂ ≥ ...，**trace 统计量**：
```
λ_trace(r) = −T · Σ_{i=r+1..k} ln(1 − λ_i)
```
- 依次检验 H₀：秩 ≤ r（r=0：无协整；r=1：至多 1 个协整向量...）；
- 统计量 > 临界值 → 拒绝 → 存在更多协整关系。

**实际结果**（三配对，k_ar_diff=1，95% 临界值）：
| 配对 | trace 统计量 | 95% 秩 |
|---|---|---|
| log(价格) × log(PE) | 23.2 | **1**（存在协整） |
| log(价格) × 10Y 利率 | 17.5 | **1** |
| log(价格) × EYG | 17.8 | **1** |

**结论**：价格与估值、价格与利率、价格与估值差**都存在长期均衡
关系**——"价格会向基本面回归"有了统计基础。

### 5.5.4 VECM：误差修正模型

**VECM（向量误差修正模型）**把"长期均衡"与"短期动态"放在一个
模型里：
```
Δx_t = α·(β'·x_{t−1}) + Γ·Δx_{t−1} + ε_t
```
- β'·x_{t−1} = **均衡偏差**（上一期偏离均衡多少）；
- α = **误差修正系数**（价格对偏差的反应速度）：
  - α < 0：价格偏离均衡后会**回拉**（均值回归）；
  - |α| 越大回拉越快；α ≈ 0：不回归（无均衡约束）。

**实际结果**：三个配对的 α 绝对值都很小（0.006-0.043）——
**回归速度慢**。经济含义：价格向估值均衡的回归不是几天/几月，
而是**3-10 年尺度**的慢回归——这完美对应了第 5.4 节"估值对长期
收益预测力强、对短期弱"的发现：**慢回归 = 长期信号，不是短期
择时工具**。

## 5.6 结果解读：这些发现意味着什么

### 5.6.1 估值是长期收益最强的预测变量（核心结论）

三条独立证据链汇聚：
1. **长期相关**：估值分位 × 未来 3/5/10 年收益 −0.59/−0.67/−0.76
   （bootstrap 全显著、单调增强）；
2. **平稳性**：log(PE) 本身是 I(0)——估值有引力中心；
3. **协整**：价格与估值存在长期均衡，慢回归。

**含义**：估值是"长期仓位"信号的**主锚**——第 6 章的条件分布
将显示"便宜时未来 3 年年化中位 +11.6%、贵时 −3.0%（亏损概率
54%）"。这就是 Compass Score 用 0.7 权重给估值的实证基础。

### 5.6.2 否定性结论：M1-M2 剪刀差领先未复现

项目启动时的候选假说"M1-M2 剪刀差领先市场 6-9 个月"（第 1 章
理论 2）——在因子层面**未复现**：
- 流动性因子滞后扫描 r ≈ −0.03~−0.05（弱）；
- Granger 不显著；
- 长期仅 36 月 bootstrap 显著（−0.38），60/120 月不显著。

**这是 v1.2"允许否定性结论"原则的实践**：研究不预设结论，数据
不支持就如实报告。可能的解释：①单变量（m1_m2_gap）比因子层
（PCA 合成）更直接——留待单变量复查；②"领先 6-9 个月"的规律
在 2008-2026 样本中不成立或已失效（货币框架变化）；③假说本身
需要更精细的窗口定义。**否定性结论的价值**：避免把未经证实的
先验当成"已知规律"写进投资规则。

### 5.6.3 短中期 vs 长期：信号的时间结构

- 短中期（1-24 月）：估值/风险/宏观状态有 Granger 预测力，但
  相关性弱（噪声大）——适合做"方向性微调"；
- 长期（3-10 年）：估值强预测、协整慢回归——适合做"仓位中枢"。

**含义**：罗盘的定位是**长期仓位配置**（Compass → 5 档仓位，
季度/半年调仓），不是短期择时——数据的信号结构支持这个定位。

## 5.7 本章小结

- **短中期**：Pearson 相关（r 的 t 检验）+ 滞后扫描（尖峰=领先
  N 月 vs 单调=均值回归）+ Granger 因果（VAR 的 F 检验：X 的过去
  是否改善 Y 的预测）；估值/风险/宏观状态 Granger 显著；
- **长期**：重叠样本使名义 n 虚高（n_eff ≈ n/(h/12)，120 月收益
  有效 n≈10）——普通 p 值假阳性；**block bootstrap**（块长 24 月
  重抽样保留自相关）是显著性主裁判；估值 3/5/10 年全显著且单调
  增强，增长/通胀部分期限被诚实淘汰；
- **均衡**：ADF（单位根检验）确认 log_price/利率 I(1)、log_pe/EYG
  I(0)；Johansen（trace 统计量）确认三个配对协整（95% 秩=1）；
  VECM 的 α 小 = 慢回归（3-10 年）——长期信号的理论基础；
- **结论**：估值 = 长期收益最强预测（三条证据链汇聚）；M1-M2
  领先假说未复现（否定性结论如实呈现）；信号结构决定罗盘定位 =
  长期仓位配置。
