# 第 6 章：条件分布与仓位模型详解——从"关系"到"可执行规则"

> 本文档是《宏观股市罗盘》教学序列的第 6 章。第 5 章证明了"估值与
> 长期收益有关系（−0.76@10 年）、宏观状态有增量"；但"有关系"和
> "能用来做投资决策"之间还隔着一层：**关系长什么样？** 估值便宜时
> 未来收益大概是多少、亏损概率多大？哪些因子真的有用、哪些是噪声？
> 怎么把这些合成一个可执行的仓位信号？
>
> 本章是**从研究到应用的转换层**，包含三块：
> - **条件分布**（P(R|State)）：状态分桶 → 桶内收益分布——回答
>   "给定当前状态，未来收益的分布是什么"；
> - **Benchmark Ladder**：逐级验证哪些因子真正改善 OOS 预测——
>   回答"哪些信号值得进模型"；
> - **Compass Score → 仓位**：把有效的信号合成一个读数、映射到
>   仓位档——回答"现在该配多少仓"。
>
> 读完本章，你应该能回答：为什么条件分布而不是点预测？分桶的
> 数学和年化公式？Ladder 的 OOS 验证逻辑和保留标准？为什么宏观
> 单因子加不好、组合加才好？Compass 的 0.7/0.3 权重从哪来？
> 博格尔公式为什么能用来对照长期收益？

---

## 6.0 本章定位：把"证据"变成"规则"

第 5 章产出的是**证据**（估值相关显著、协整存在、宏观有增量），
但证据不能直接操作——投资者需要的是一句话："**现在该配多少仓？**"
本章完成这个转换：

```
第 5 章证据 → 条件分布（状态→收益分布表）→ Benchmark Ladder
（有效因子筛选）→ Compass Score（合成读数）→ 仓位映射（可执行）
```

每一步都保留了"诚实"：条件分布报告的是分布（不是点）、Ladder
标注了过拟合风险、Compass 权重明确是"先验"（实证校准在下一章）。

## 6.1 为什么是条件分布，而不是点预测

### 6.1.1 点预测的问题

一个直觉做法：回归出"估值分位 → 未来 3 年年化收益 = 7.2%"，然后
说"现在估值高，预期收益 7.2%"。问题：

1. **虚假精确**：长期收益的分散度极大——第 5 章的数据里，36 月
   收益的 Q25-Q75 跨度约 20-30 个百分点。说"预期 7.2%"暗示精确到
   0.1 个百分点，但真实分布从 −5% 到 +20% 都有可能；
2. **掩盖风险**：点预测不告诉"亏损概率"——估值贵的桶中位数是
   负的，但点预测的置信区间会掩盖"54% 概率亏损"这个关键信息；
3. **误导仓位**：仓位决策需要的是"分布的形状"——分布宽（不确定
   性大）应该轻仓，分布窄（确定性强）才可以重仓。点预测丢弃了
   分布宽度信息。

### 6.1.2 条件分布的定义

**条件分布**：给定状态 State_t（如"估值处于历史低位"），未来
h 个月收益 R(t,t+h) 的条件分布：
```
P( R(t, t+h) | State_t )
```
不报告单个预测值，而是报告分布的**关键统计量**（四件套）：
- **中位数**：条件的中心位置（"一半时候高于它"）；
- **Q25 / Q75**：四分位区间——分布宽度的度量（不确定性）；
- **P(R<0)**：亏损概率——风险的核心度量；
- **MDD 中位数**：持有期内的最大回撤（最坏情况的中心估计）。

### 6.1.3 因变量四件套（v1.2）

每个状态桶同时报告四个"收益版本"，因为名义收益会误导：
| 指标 | 公式 | 回答的问题 |
|---|---|---|
| Total Return 年化 | (1+R)^(12/h) − 1 | 名义上赚多少 |
| Real Return 年化 | Total − 持有期年化通胀 | 购买力赚多少（2011 年名义 6% 其实跑输） |
| Excess Return 年化 | Total − 无风险利率 | 相对现金多赚多少（仓位配置看这个） |
| P(R<0) + MDD | 收益 <0 的比例；回撤中位数 | 亏损概率与最坏情况 |

**教学点**：Real 回答"购买力增长"，Excess 回答"相对现金的增值"——
长期配置的决策基准是 Excess（如果股票跑不赢现金，为什么要配？）。

## 6.2 状态分桶的数学

### 6.2.1 分桶方法

**做法**：状态变量（估值因子 / 宏观状态）的 expanding 分位 →
三分桶（低/中/高）：
```
P_t = expanding 分位（无前视，第 3 章方法）
桶 = 低(冷) if P_t ≤ 1/3;  中 if 1/3 < P_t ≤ 2/3;  高(热) if P_t > 2/3
```

**为什么三分桶**（而不是五分/十分）：
- 样本量：223 个月 / 3 桶 ≈ 每桶 60-70 个月——桶内样本足够估计
  中位数/分位数（太细的桶样本太少，统计量噪声大）；
- 粒度：三分桶能区分"便宜/中性/贵"三个状态——对仓位决策足够
  （第 7 章的五档仓位是"连续映射"，分桶是"分布描述"）；
- 可解释：低/中/高是人的直觉分类。

**为什么 expanding 分位分桶（而非全样本）**：与第 3 章一致——
分桶本身不能使用未来信息（决策月 t 的"便宜/贵"判定只能基于
t 之前的历史）。虽然条件分布是描述性的（研究用途），统一无前视
口径保证与第 7 章回测的一致性。

### 6.2.2 年化公式

桶内每个观测的累计收益 R(t,h) 转年化：
```
Annualized = (1 + R)^(12/h) − 1
```
- h = 36 月：年化 = (1+R)^(1/3) − 1；
- 为什么年化：3 年和 10 年的累计收益不可比，年化后"每年赚多少"
  可直接对比。

### 6.2.3 桶内统计量

对桶内所有观测的年化收益 {a₁..a_m}：
- 中位数：排序后第 (m+1)/2 个；
- Q25/Q75：排序后 25%/75% 分位；
- P(R<0)：aᵢ < 0 的比例（注意：用累计收益 R 判亏损，不是年化——
  年化符号与累计一致，等价）；
- MDD 中位数：桶内各观测的 future_max_drawdown 的中位数。

## 6.3 条件分布的实际结果与解读

### 6.3.1 估值分桶（核心结果，全持有期单调）

| 桶 | 36 月年化中位 | 60 月 | 84 月 | 120 月 | 36 月亏损概率 | 36 月 MDD 中位 |
|---|---|---|---|---|---|---|
| 低（便宜） | +11.6% | +9.0% | +7.9% | +7.3% | 29% | −35% |
| 中 | +6.1% | +5.3% | +5.5% | +6.2% | 21% | −31% |
| 高（贵） | **−3.0%** | +1.6% | +2.1% | +3.1% | **54%** | −37% |

**怎么读这张表**（教学重点）：
1. **单调性**：便宜→贵，每个持有期的年化中位都递减——"估值越低，
   未来收益越高"在 4 个持有期全部成立。这是第 5 章相关性的"分布
   版"呈现；
2. **亏损概率**：36 月视角，贵桶 54% 概率亏损（中位数 −3.0%）——
   "在估值历史高位买入，3 年后大概率亏钱"。这是给"现在该不该买"
   的最直接答案；
3. **持有期效应**：120 月贵桶 +3.1%（正）但仍低于便宜桶 +7.3%——
   长期（10 年）均值回归会把收益拉回正区间，但**贵时的起点低，
   10 年也追不平**；
4. **MDD 差异不大**（−31%~−37%）：回撤主要受市场自身波动驱动，
   估值状态对"持有期内最坏情况"的区分弱——**估值影响的是终点
   收益，不是途中波动**。

### 6.3.2 宏观状态分桶（辅助信号）

| 桶 | 36 月年化中位 | 120 月 | 36 月亏损概率 |
|---|---|---|---|
| 低（冷） | +8.8% | +8.5% | 4% |
| 中 | +9.8% | +7.4% | 15% |
| 高（热） | **+6.7%** | +6.2% | 31% |

**怎么读**：
1. **非单调**：36 月冷/中/热 = +8.8/+9.8/+6.7——中桶最高，不是
   单调递减。宏观状态对短期收益的区分**不如估值清晰**；
2. **热桶明确低**：无论 36 月还是 120 月，热桶都是最低——"宏观
   过热后收益低"（过热 → 政策收紧 → 市场承压）是稳定的；
3. **含义**：宏观状态是**微调信号**——"过热时降低风险暴露"，
   但不足以单独决定仓位（冷/中的差异小）。

### 6.3.3 实证对先验的支持

第 1 章的理论（估值均值回归 + 美林时钟）在这里得到**分布级**的
确认：估值分桶全持有期单调（估值 = 主信号）、宏观热桶收益低
（宏观 = 微调信号）。这就是第 6.6 节 Compass 权重 0.7/0.3 的
**数据依据**（先验 + 数据方向一致）。

## 6.4 Benchmark Ladder：逐级验证的逻辑

### 6.4.1 问题：加变量真的有用吗？

直觉上"信号越多越好"——但统计上每加一个特征就多一分过拟合风险
（模型在训练集上拟合噪声，OOS 上失效）。**Benchmark Ladder** 的
设计：从最简单的模型（历史均值）开始，**逐级加入**因子，每一步
都在**样本外（OOS）**检验"新增因子是否真的改善预测"——不改善
就不保留。

### 6.4.2 阶梯设计（v1.2 定案）

```
Model0: 历史均值（买入持有基线）——不加任何因子
Model1: + 估值因子
Model2: + 利率因子
Model3: + 流动性/信用因子
Model4: + 增长/通胀/居民/风险/宏观状态（全部宏观）
```

**为什么这个顺序**：从"最强信号"（估值，第 5 章证据）开始，逐级
加次要信号——每一步都在检验"**在已有信号之上，新增信号还有没有
增量**"（而不是从头比谁更好）。

### 6.4.3 OOS 评估的数学（walk-forward expanding OLS）

**训练/预测切分**：
```
对每个 t ≥ 60：
  训练窗口 = {1..t−1}（expanding：只用过去）
  用训练窗口拟合 OLS：R(36) = β₀ + Σβᵢ·Xᵢ
  预测 t 的 36 月收益：R̂(t)
  与真实 R(t) 比较 → 记录 OOS 误差
```
- **expanding 训练**：样本逐月增加，模拟"每个月用当时能有的全部
  历史重估一次模型"——这就是 walk-forward（滚动前向验证）的最简
  形式（第 7 章会做更严格的每 12 月重估版本）；
- **无前视**：训练窗口只到 t−1，特征（因子分位）本身无前视
  （第 3 章），预测 t 只用了 t 之前的信息；
- **min 60 个月**：保证训练样本足够（9 特征至少 60+ 观测）。

**OOS 度量**：
```
RMSE = √( (1/N)·Σ(R̂ᵢ − Rᵢ)² )        —— 预测误差的均方根
MAE  = (1/N)·Σ|R̂ᵢ − Rᵢ|             —— 平均绝对误差
方向一致率 = (1/N)·Σ 1{sign(R̂ᵢ) = sign(Rᵢ)}  —— 涨跌方向猜对的比例
```

**保留标准**：Model_k 相对 Model_{k−1} 的 RMSE 改善 > 1% 才保留
新增因子。为什么 1%：
- 阈值防过拟合——小于 1% 的改善在重叠样本（第 5 章）下可能是
  噪声；
- 估值（+10.9%）和宏观组合（+30.4%）的改善远大于阈值，是真实
  信号；利率的 −10% 明确是负贡献。

## 6.5 Ladder 的实际结果与解读

### 6.5.1 结果表

| 模型 | RMSE | 方向一致率 | vs Model0 | 判定 |
|---|---|---|---|---|
| Model0 历史均值 | 0.289 | 75.6% | — | 基线 |
| Model1 +估值 | 0.257 | 75.6% | **+10.9%** | ✓ 保留 |
| Model2 +利率 | 0.283 | 74.0% | −10.0%（vs M1） | ✗ 不保留 |
| Model3 +流动性/信用 | 0.283 | 72.4% | −0.3%（vs M2） | ✗ 不保留 |
| Model4 全部宏观 | 0.201 | 81.1% | **+30.4%** | ✓ 保留 |

**最终保留阶梯：Model0 → Model1 → Model4**。

### 6.5.2 为什么利率/流动性/信用单独加不好

- Model2（+利率）RMSE 反而恶化（−10%）——利率因子单独加入是
  **噪声特征**：利率与 36 月收益的相关弱且不稳定（第 5 章利率
  不显著），OLS 在训练集上"拟合了噪声"，OOS 上惩罚；
- Model3（+流动性/信用）几乎无变化（−0.3%）——它们的信息与
  已有特征重叠（流动性/信用与估值的相关性高，第 1 章理论网络
  里"流动性是估值的潮汐"）。

### 6.5.3 为什么 Model4 组合加就好（协同效应）

- Model4 一次加入 5 个宏观特征（增长/通胀/居民/风险/宏观状态），
  OOS RMSE 0.201（改善 +30.4%）——**组合捕捉到了单因子没有的
  信息**；
- 解释：宏观状态是**8 模块因子的合成**（第 4 章），它代表"经济
  整体状态"——单个宏观因子（如利率）与收益的关系弱，但"增长+
  通胀+居民+风险+宏观状态"的组合刻画了经济环境的**全貌**，这个
  全貌与收益的关系比任何单因子都强；
- 统计学上：组合特征提供了**互补信息**（正交部分），而单个因子
  的增量大部分被已有特征（估值）吸收。

### 6.5.4 过拟合风险声明（候选结论）

**⚠️ 必须声明**：Model4 有 9 个特征，训练窗口 60-160 个月——
参数个数/样本量比值偏高，+30.4% 的改善可能是部分过拟合。因此：
- 本结论标为**候选**（不是定论）；
- 第 7 章做严格验证：①分时段增量检验（2015-19 / 2020-26 两段都
  改善才稳定）②每 12 月重估的 walk-forward 回测 ③如果 OOS 不
  稳定 → w_macro = 0（v1.2 允许否定性）。

## 6.6 Compass Score：合成读数

### 6.6.1 公式与权重来源

```
Compass Score(t) = 0.7 × 估值因子分位(t) + 0.3 × 宏观状态分位(t)
```

**权重 0.7/0.3 从哪来**：
- 第 5 章：估值是长期收益最强预测（−0.76@10 年、bootstrap 全显著、
  协整慢回归）——主信号；
- 6.3：估值分桶全持有期单调（主）、宏观状态热桶低但冷/中差异小
  （辅）；
- 6.5：Ladder 显示估值单独有效（+10.9%）、宏观组合有效（+30.4%）
  ——两者都有增量，估值为主、宏观为辅；
- **定位**：这是 **structural prior（先验假设）**——权重不是
  优化出来的（优化会过拟合），而是基于证据方向设定的先验；
  第 7 章回测会检验"这个先验权重是否有效"（0.5/0.5、0.8/0.2
  变体作为稳健性）。

**为什么两个都用 expanding 分位**：估值因子分位和宏观状态分位
都无前视（第 3 章方法）——Compass 在 t 时刻的值只用 t 之前信息，
可以直接用于回测（第 7 章）。

### 6.6.2 当前读数（2026-07）

```
Compass = 0.7 × (+0.88 估值分位) + 0.3 × (−0.23 宏观状态)
        = +0.399 → 历史 80% 分位 → 偏高档
```
- 估值分位 +0.88：PE/PB 历史高位（贵）；
- 宏观状态 −0.23：综合偏冷（信用收缩 −0.95、信心 −1.13 拖累）；
- 净效果：**偏高档**（估值高是主因，宏观冷稍微缓冲）。

## 6.7 仓位映射

### 6.7.1 五档规则（逆向）

Compass 分位 → 仓位档（**注意方向是逆向的**——分位高=贵+热=低配）：

| Compass 分位 | 档位 | 仓位 |
|---|---|---|
| ≤20%（便宜+冷） | 高配 | 100% |
| 20-40% | 偏高 | 85% |
| 40-60% | 中性 | 70% |
| 60-80% | 偏低 | 55% |
| >80%（贵+热） | 低配 | 40% |

**为什么逆向**：Compass 高 = 估值贵 + 宏观热 → 未来收益低（6.3
实证）→ 应该低配。**这是反人性的**（贵的时候市场情绪高涨，多数
人想加仓），但数据支持：贵桶 36 月亏损概率 54%。

**为什么档位是 40%-100% 而不是 0%-100%**：
- 长期配置不清零（A 股长期有正收益，空仓的机会成本高）；
- 40% 是最低暴露（不是清仓），100% 是最高（不杠杆）——保守区间，
  留出调仓空间。

**比例由回测确定（不是先验定死）**：40/55/70/85/100 是**初始
参数**，第 7 章回测会检验（阈值 ±5pp 的敏感性）。v1.2 明确：
"具体比例由回测确定，不先验固定"。

## 6.8 博格尔公式对照

### 6.8.1 公式的数学推导

**博格尔公式**（John Bogle，指数基金之父）：长期股票收益 ≈
```
股息率 + 盈利增长率 + 估值变化率
```
推导（从 DDM 出发）：价格 P = E × PE（E 是盈利）：
```
长期收益 ≈ ΔP/P ≈ ΔE/E + ΔPE/PE = 盈利增长率 + 估值变化
加上股息：总收益 ≈ 股息率 + 盈利增长 + 估值变化
```
其中"股息率 + 盈利增长" ≈ **盈利收益率 1/PE**（Gordon 模型：
P = D/(r−g) → E/P ≈ D/P + g = 股息率 + 增长）。

**所以博格尔公式的近似形式**：
```
长期收益 ≈ 1/PE + 估值变化率
```

### 6.8.2 我们的对照（120 月数据）

| 项 | 值 |
|---|---|
| 盈利收益率 1/PE 中位 | 8.05% |
| 实际 120 月年化收益中位 | 6.61% |
| 隐含"盈利增长+估值变化" | −1.44%/年（估值压缩拖累） |
| 便宜桶（1/PE 高）120 月年化 | 7.27% |
| 贵桶（1/PE 低）120 月年化 | 4.49% |

**怎么读**：
1. 8.05% − 1.44% ≈ 6.61%——**博格尔公式成立**：1/PE 高时收益高，
   1/PE 低时收益低（便宜桶 7.27% vs 贵桶 4.49%，差 2.8pp/年）；
2. 隐含估值压缩 −1.44%/年：样本期内 PE 中枢下行（2008 年高 PE
   时代 → 现在较低）——估值变化对长期收益是**负贡献**；
3. **教学点**：博格尔公式把"估值→收益"的关系拆成可理解的三部分
   ——股息/盈利（基本面贡献）+ 估值变化（市场情绪贡献）。长期
   收益主要由基本面贡献，估值变化是"额外奖励/惩罚"：低估值买入
   获得正的估值变化奖励（回归），高估值买入承受负的估值变化
   （压缩）——**这就是均值回归的收益表达**。
