# 7.0 回测不是“把历史数据跑一遍”

回测真正模拟的是一个决策过程：

\[
\mathcal I_t
\rightarrow
Signal_t
\rightarrow
Weight_{t+1}
\rightarrow
PortfolioReturn_{t+1}
\]

其中：

\[
\mathcal I_t
\]

是时点 \(t\) 真正可知的信息集。

一个合法回测必须满足：

\[
\boxed{
Signal_t=f(\mathcal I_t)
}
\]

并且：

\[
Weight_{t+1}
\]

只能在信号形成之后执行。

这比“代码没有报错”严格得多。

---

# 7.1 四个时间点必须分开

## 7.1.1 Reference Period

宏观数据描述哪个时期。

## 7.1.2 Available Date

市场什么时候能看到它。

## 7.1.3 Decision Date

本项目是每月最后一个 A 股交易日。

## 7.1.4 Execution Date

下一真实交易日。

因此：

\[
\boxed{
Reference
\neq
Available
\neq
Decision
\neq
Execution
}
\]

---

# 7.2 最严格的仓位时序

设月末决策日：

\[
D_t
\]

当天收盘后得到：

\[
Compass_t
\]

则执行：

\[
N(D_t)
\]

即下一真实交易日。

所以更严格的组合状态应该写：

\[
w_{N(D_t)}
=
g(Compass_t)
\]

而不是模糊地说：

```text
“上月信号决定本月仓位”
```

后者在月频回测里是合理近似，但日度执行版本更精确。

---

# 7.3 为什么 shift(1) 是必要但不总是充分

如果：

```python
weight = signal.shift(1)
```

说明没有用“本月结束后才知道的信号”赚本月收益。

这是正确的。

但还必须保证：

1. signal 本身 PIT-safe；
2. factor loading 没用未来；
3. percentile 没用未来；
4. target 没参与 signal construction；
5. execution 没假设月初即可成交。

所以：

\[
\boxed{
shift(1)
\text{ 只能解决一类前视}
}
\]

# 7.4 最严格的组合收益公式

设股票权重：

\[
w_t
\]

现金权重：

\[
1-w_t
\]

股票收益：

\[
R_{e,t}
\]

现金收益：

\[
R_{f,t}
\]

交易成本：

\[
C_t
\]

则组合净收益：

\[
\boxed{
R_{p,t}
=
w_tR_{e,t}
+
(1-w_t)R_{f,t}
-
C_t
}
\]

---

# 7.5 如果现金收益设为 0，意味着什么

原稿用：

\[
R_f=0
\]

作为保守处理。

这不是“真实现金资产”。

它实际上等价于：

> 未投资部分放在零收益账户。

如果真实现金：

\[
R_f>0
\]

策略总收益通常会提高。

---

# 7.6 但“现金设 0 一定对策略更保守”也要加一个限定

如果 benchmark 是：

\[
100\%\ equity
\]

现金设 0 确实通常压低低仓位策略收益。

但风险调整指标如 Sharpe 还取决于你使用的：

\[
risk-free\ rate
\]

如果组合收益现金腿按 0，而 Sharpe 又减 2% rf，就出现口径不完全一致。

因此最好统一：

### Portfolio wealth

现金腿实际计息。

### Sharpe

同一 risk-free reference。

# 7.7 推荐的三套现金口径

## A. Zero Cash

最保守 sanity check。

## B. Money-market Proxy

例如短期国债/存款。

## C. Realistic Implementable Cash

投资者实际可获得的货币基金/短债收益。

三套都做，比只做 0 更完整。

# 7.8 净值曲线的数学

初始：

\[
NAV_0=1
\]

递推：

\[
NAV_t
=
NAV_{t-1}(1+R_{p,t})
\]

所以：

\[
NAV_T
=
\prod_{t=1}^{T}
(1+R_{p,t})
\]

---

# 7.9 为什么不能把月收益简单相加

因为收益复利：

\[
(1+r_1)(1+r_2)-1
\]

不等于：

\[
r_1+r_2
\]

差一个交互项：

\[
r_1r_2
\]

---

# 7.10 年化收益 CAGR

如果总月数：

\[
N
\]

年化：

\[
\boxed{
CAGR
=
NAV_N^{12/N}-1
}
\]

这是几何收益。

---

# 7.11 算术平均与几何平均

算术：

\[
\bar r
=
\frac1N\sum r_t
\]

几何：

\[
g
=
\left(
\prod(1+r_t)
\right)^{1/N}-1
\]

一般：

\[
g\le\bar r
\]

波动越大，两者差越大。

---

# 7.12 Volatility Drag

近似：

\[
g
\approx
\bar r-\frac12\sigma^2
\]

所以降低波动即使不提高算术平均收益，也可能改善长期复利效率。

这是风险控制策略的重要经济逻辑。

---

# 7.13 年化波动

月收益标准差：

\[
\sigma_m
\]

常见年化：

\[
\sigma_{ann}
=
\sigma_m\sqrt{12}
\]

---

# 7.14 \(\sqrt{12}\) 需要什么假设

如果月收益独立且方差稳定：

\[
Var\left(
\sum_{m=1}^{12}r_m
\right)
=
12\sigma_m^2
\]

因此：

\[
\sigma_{ann}
=
\sqrt{12}\sigma_m
\]

若存在自相关：

\[
Var(\sum r_t)
=
12\sigma^2
+
2\sum_{k=1}^{11}(12-k)\gamma_k
\]

所以简单 \(\sqrt{12}\) 只是标准近似。

---

# 7.15 策略收益更容易产生自相关

因为：

\[
w_t
\]

由慢变化 Compass 决定。

所以仓位序列具有 persistence。

因此策略月收益：

\[
R_{p,t}
\]

的自相关可能与 benchmark 不同。

这意味着更严格的风险估计可以使用 realized annual return 或 HAC volatility 作为辅助。

---

# 7.16 Maximum Drawdown

running peak：

\[
Peak_t
=
\max_{s\le t}NAV_s
\]

drawdown：

\[
DD_t
=
\frac{NAV_t}{Peak_t}-1
\]

最大回撤：

\[
\boxed{
MDD
=
\min_tDD_t
}
\]

---

# 7.17 MDD 的三个特点

### Path-dependent

只知道起点终点不够。

### One-event dominated

整个 11 年样本可能由一次危机决定。

### Sample-length dependent

样本越长，观察到极端 MDD 的机会越大。

所以跨不同长度回测比较 MDD 时要谨慎。

---

# 7.18 MDD 应配合什么一起看

建议同时报告：

- average drawdown；
- drawdown duration；
- recovery time；
- worst 3 drawdowns；
- Ulcer Index。

---

# 7.19 Drawdown Duration

如果峰值在：

\[
t_0
\]

直到：

\[
t_1
\]

恢复：

\[
NAV_{t_1}\ge NAV_{t_0}
\]

则 duration：

\[
t_1-t_0
\]

投资者实际痛苦不仅来自：

\[
\text{跌多深}
\]

还来自：

\[
\text{多久回本}
\]

---

# 7.20 Sharpe Ratio

月度 excess return：

\[
r_t^e=r_t-r_{f,t}
\]

Sharpe：

\[
SR
=
\frac{
E(r^e)
}{
\sigma(r^e)
}
\sqrt{12}
\]

这比“年化收益减 rf 再除年化波动”更严格。

---

# 7.21 为什么 Sharpe 用算术 excess mean

Sharpe 是：

\[
\boxed{\text{mean-variance ratio}}
\]

不是 CAGR / volatility ratio。

所以最好使用：

\[
\bar r_{monthly}^{excess}
\]

年化。

---

# 7.22 原稿 Sharpe 的口径需要明确

如果用：

\[
(CAGR-r_f)/\sigma
\]

它是常见实践近似，但严格定义与：

\[
\frac{\bar r^e}{s_r}
\]

不完全相同。

本项目最终报告应标注具体版本。

---

# 7.23 Sortino Ratio

定义 target return：

\[
MAR
\]

下行偏差：

\[
DownsideDeviation
=
\sqrt{
E[
\min(r_t-MAR,0)^2
]
}
\]

Sortino：

\[
\frac{
E(r_t-MAR)
}{
DownsideDeviation
}
\]

---

# 7.24 “只对负收益算标准差”只是近似说法

严格 downside deviation 不是：

> 把正收益删掉，再对负收益做普通 std。

而是：

\[
\sqrt{
\frac1N
\sum
\min(r_t-MAR,0)^2
}
\]

正收益贡献：

\[
0
\]

但仍计入样本数 N。

---

# 7.25 Calmar Ratio

常见：

\[
Calmar
=
\frac{
CAGR
}{
|MDD|
}
\]

它强调：

\[
\boxed{\text{return per unit worst drawdown}}
\]

---

# 7.26 Calmar 的局限

MDD 是一个极端单点。

如果：

\[
MDD
\]

只由一次事件产生，Calmar 对单次危机极度敏感。

所以不应只凭 Calmar 判断策略。

---

# 7.27 Turnover

如果只有股票+现金：

\[
TO_t
=
|w_t-w_{t-1}|
\]

这是单资产权重变化。

---

# 7.28 更严格的双边交易量

从股票：

\[
w_{t-1}
\]

调到：

\[
w_t
\]

实际买/卖名义量比例近似：

\[
|w_t-w_{t-1}|
\]

因此当前定义合理。

但如果未来多资产组合：

\[
TO_t
=
\frac12
\sum_i
|w_{i,t}-w_{i,t^-}|
\]

更标准。

---

# 7.29 月均 Turnover 5.1% 应怎样解释

它不等于：

> 每 20 个月才调仓一次。

因为可能每个月小幅调整。

更准确：

> 每月平均有 5.1% 的组合资本发生股票/现金再配置。

年化近似：

\[
12\times5.1\%
\approx61\%
\]

但不能把它直接理解为“61%资金全年只交易一次”，因为路径不同。

---

# 7.30 交易成本模型

如果单边成本：

\[
c
\]

则：

\[
Cost_t
=
c\cdot TO_t
\]

如果包含：

- commission；
- bid-ask；
- market impact；
- tax；

应分项。

# 7.31 对 ETF 策略交易成本通常不大，但不能省略

若：

\[
TO_{annual}\approx60\%
\]

单边综合成本：

\[
10bp
\]

年度成本约：

\[
0.06\%
\]

确实很小。

但必须计算，而不是凭“换手低”断言。

# 7.32 Rebalancing Frequency

信号每月更新，不等于每月必须交易。

可以比较：

```text

```

# 7.33 为什么低频再平衡可能更适合长期信号

如果 Compass 是慢变量：

\[
Corr(C_t,C_{t-1})\approx高
\]

月度交易可能主要追踪微小 score noise。

低频 rebalance 可以：

- 降 turnover；
- 降 chattering；
- 降 estimation noise。

# 7.34 Benchmark 选择决定“策略是否有效”的含义

当前 benchmark：

\[
100\%\ CSI300TR
\]

回答：

> 动态降仓能否改善相对长期满仓？

这非常合理。

但还可以增加：

### Constant 70%

检验动态 timing 是否胜过固定中性仓位。

### 60/40 Equity-Cash

检验风险改善是不是单纯因为平均股票仓位更低。

### Volatility-matched Equity

检验 Sharpe 改善是不是只来自降低 beta。

# 7.36 Dynamic Timing Alpha

可以构造固定权重 benchmark：

\[
w^*=\bar w_{strategy}
\]

收益：

\[
R_t^{fixed}

w^*R_{equity,t}
+
(1-w^*)R_{cash,t}

\boxed{\text{timing value}}

# 7.39 Up Capture / Down Capture

牛市 capture：

\[
Capture_{up}
=
\frac{
Return_{strategy,up}
}{
Return_{market,up}
}
\]

熊市：

\[
Capture_{down}
=
\frac{

理想防御策略：

\[
Capture_{up}<1
\]

\[

\[

\]

显著更低。

# 7.41 回测窗口是否真正 OOS，要看规则何时冻结

原稿称：

```text
2015–2026 OOS
```

这个说法只有在以下条件成立时才严格：

> 2015 年以前，Compass 的变量、归一化、0.7/0.3、五档阈值全部已经固定，不再利用 2015 以后数据调整。

如果这些规则是在看过 2015–2026 结果后形成的，那么它更准确是：

\[
\boxed{\text{historical pseudo-OOS / walk-forward simulation}}
\]

而不是真正 untouched holdout。

---

# 7.42 Pseudo-OOS 与 True OOS

## Pseudo-OOS

时间顺序严格，但研究设计是在全样本研究过程中形成。

## True OOS

规则冻结后出现的新数据。

真正最强证据永远来自：

\[
\boxed{\text{future live OOS}}
\]

---

# 7.43 这不否定历史回测价值

历史 pseudo-OOS 仍然比：

```text
full-sample fit
```

强得多。

但术语必须诚实。

建议写：

> 2015–2026 historical walk-forward evaluation window。

如果规则确实在 2015 前冻结，才叫严格 OOS holdout。

# 7.44 Start-date Sensitivity

比较：

```text
2015
2016
2017
```

可以检查起点依赖。

但这些窗口高度重叠。

所以三组结果不是三次独立验证。

# 7.45 为什么重叠稳健性结果不能简单累积证据

例如：

```text
2015-2026
2016-2026
2017-2026
```

共享绝大多数月份。

它们只能说明：

\[
\boxed{\text{结果不完全由首年决定}}
\]

而不是提供三倍证据。

# 7.46 参数敏感性真正要检查什么

如果改变：

\[
\theta
\]

策略表现：

\[
Performance(\theta)
\]

应当平滑变化。

稳定模型通常存在：

\[
\boxed{\text{parameter plateau}}
\]

而不是只有一个尖峰最佳参数。

---

# 7.47 Plateau 比最优点更重要

如果：

```text
0.5/0.5 → Sharpe 0.20
0.7/0.3 → 0.16
0.8/0.2 → 0.16
```

都差不多，说明规则对权重不敏感。

这是好事。

不要为了 0.04 Sharpe 追 0.5/0.5。

---

# 7.48 但参数敏感性也必须算统计误差

11 年月度样本下：

\[
Sharpe=0.16
\]

与：

\[
0.20
\]

的差异可能完全处于 sampling noise。

所以不应排序得过细。

---

# 7.49 Sharpe Ratio 的 Sampling Error

粗略独立正态下：

\[
SE(SR)
\approx
\sqrt{
\frac{
1+\frac12SR^2
}{
T
}
}
\]

真实时间序列还有自相关、非正态。

所以 138 个月样本的 Sharpe uncertainty 并不小。

---

# 7.50 为什么 Sharpe 0.16 vs 0.13 不能只看数字说“显著改善”

差：

\[
0.03
\]

很小。

应该通过：

- block bootstrap；
- Ledoit-Wolf Sharpe difference test；
- Jobson-Korkie（谨慎使用）；

估计不确定性。

# 7.53 Annual Performance Table 的局限

按自然年切分是方便展示。

# 7.135 本章最常见的二十五个误解

1. “shift(1) 就保证完全无前视。”——错误。
2. “现金设 0 一定与 Sharpe 的 rf 口径一致。”——不一定。
3. “\(\sqrt{12}\) 年化波动严格成立。”——需要弱自相关假设。
4. “Sharpe 用 CAGR/risk 就是严格定义。”——常见近似，不是唯一标准。
5. “Sortino 就是负收益样本的标准差。”——不严格。
6. “月均换手 5% 等于 20 个月调一次仓。”——错误。
7. “2015–2026 就一定是真正 OOS。”——取决于规则何时冻结。
8. “多个起点都是独立稳健性证据。”——高度重叠。
9. “参数最优点比参数平台更重要。”——相反。
10. “Sharpe 0.20 一定显著优于 0.16。”——不一定。
11. “MDD 改善自动证明 timing 有效。”——可能只是平均仓位低。
12. “熊市少跌一定是 Compass alpha。”——可能只是 beta 低。
13. “滞后两期等于真实 vintage PIT 测试。”——错误。
14. “滞后版更好就证明不存在修订偏误。”——错误。
15. “两段 OOS 都改善就证明宏观稳定。”——只是支持证据。
16. “rolling normalization 回测差就被永久否定。”——仍需未来验证。
17. “换一个指数有效就证明跨市场普适。”——需要 signal universe 匹配。
18. “稳健性测试越多越可信。”——过多测试会 data mine。
19. “交易成本低可以不算。”——错误。
20. “CAGR 低一点但 Sharpe 高就一定更好。”——取决于投资者 utility。
21. “满仓是唯一 benchmark。”——需要 fixed-risk comparator。
22. “回测成功就是未来有效。”——错误。
23. “策略失效时应该马上调参数。”——会 adaptive overfit。
24. “撤回条件是主观附加条款。”——它是可证伪框架核心。
25. “历史回测是研究终点。”——真正终点是 live prospective OOS。

# 7.139 本章最终结论

第七章真正要建立的是：

\[
\boxed{\text{可信的策略证据等级}}
\]

而不是一条漂亮净值曲线。

当前历史结果最值得保留的观察是：

1. Compass 动态降仓显著降低了 realized volatility 与 MDD；
2. 代价是一定的牛市 opportunity cost；
3. 参数与部分替代设定下方向较稳定；
4. 宏观增量在多个阶段存在候选支持；
5. 策略整体表现更像“风险控制型长期配置”，而不是追求绝对超额收益的择时系统。

但在正式把它称为“已验证策略”之前，还必须回答几个更严格的问题：

\[
\boxed{
\begin{aligned}
&\text{是否优于同平均股票仓位的固定组合？}\\
&\text{交易成本和真实现金收益后是否仍成立？}\\
&\text{历史规则是否真正冻结于评估窗口之前？}\\
&\text{PIT vintage 是否已经真实重建？}\\
&\text{策略指标差异的置信区间是否稳定？}\\
&\text{未来 live OOS 是否继续成立？}
\end{aligned}
}
\]

因此更成熟的阶段性结论是：

> 当前 Compass 规则已经通过了一系列历史前向、参数、起点、指数和时间稳定性检验，显示出有意义的风险控制特征；但它仍应被视为一个经过历史验证的候选配置规则，而不是已经证明具有永久超额收益能力的最终策略。真正最终证据来自冻结规则后的 prospective live OOS。
