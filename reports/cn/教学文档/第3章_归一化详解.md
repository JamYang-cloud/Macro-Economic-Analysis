# 第 3 章：归一化详解——expanding 分位的数学原理与选型逻辑

> 本文档是《宏观股市罗盘》教学序列的第 3 章。第 2 章把原始数据清洗
> 成了"PIT 对齐、口径标记、缺失归因"的面板；但面板里各变量还是
> 原始量纲——PE 是十几倍、M2 增速是百分之几、利率是几个点、央行
> 资产负债表是几万亿。**量纲不同，就无法比较，更无法进 PCA 或回归。**
> 本章讲归一化：把每个变量转成"这个值在它自己的历史上处于什么位置"
> 的 [-1,1] 分位值，以及**为什么选 expanding 分位而不是别的标准化
> 方法**——这是整个方法链上第一个"为什么"级别的决策。
>
> 读完本章，你应该能回答：归一化要满足哪四个要求？min-max、
> z-score、robust z、分位法各自的数学与缺陷？expanding 分位为什么
> 无前视、为什么对极值稳健？warm-up 和 regime 分组是什么、样本不足
> 时怎么决策？

## 3.0 为什么需要归一化

### 3.0.1 量纲问题

把原始数据直接进模型会遇到三类问题：

1. **量纲不可比**：PE=15 倍与 M2 增速=7% 与 10Y 利率=2.3%——数值
   大小不代表任何相对含义。"PE=15" 是高是低？要看历史；"M2=7%"
   是高是低？也要看历史。原始值本身不携带"相对位置"信息。
2. **方差主导**：PCA 和回归对变量的"尺度"敏感——方差大的变量
   天然主导结果（央行资产负债表万亿级数值的方差碾压 CPI 增速）。
   不归一化，PCA 的第一主成分会被"数值大"的变量绑架，而不是被
   "经济含义"主导。
3. **极值扭曲**：2008 年 PPI 同比冲到 10%，2015 年融资余额翻倍——
   这些极端值若以原始尺度进入模型，会扭曲均值、方差和相关性。

### 3.0.2 归一化要满足的四个要求（v1.2 定案）

| 要求 | 含义 | 不满足的后果 |
|---|---|---|
| ① 无前视 | 归一化参数只用 {X₁..X_t} 估计 | 回测虚高（提前知道未来分布） |
| ② 极值稳健 | 单个极端值不主导结果 | 均值/方差被 2008/2015 拉爆 |
| ③ 有界可比 | 输出值域固定、跨变量可比 | PCA 输入不同质（z-score 无界 vs 分位有界） |
| ④ 可解释 | 值有直观含义 | 模型输出无法向人解释 |

这四个要求就是选型判据。下面逐一考察候选方法。

## 3.1 候选方法的数学原理

### 3.1.1 min-max 全样本归一化（弃用）

**公式**：
```
x̃_t = (x_t − min(X)) / (max(X) − min(X)) ∈ [0, 1]
```

**数学性质**：
- **极值敏感（致命）**：min 和 max 是**单点统计量**——只要有一个
  极端值（2008 年 PPI 10%），整个映射就被它锚定：所有其他值被
  压到接近 0 的小区间，分辨度丧失。数学上，min/max 是样本的
  极值序统计量，其方差随样本增大而**增大**（极值分布理论），
  不是收敛的。
- **前视偏差（致命）**：全样本的 min/max 用了未来的数据——t 时刻
  的值映射到 [0,1] 依赖"未来才出现的极值"。
- 有界 ✓、可解释 △（只表示"区间内位置"）。

**结论**：两个致命缺陷，直接弃用。

### 3.1.2 全样本 z-score（弃用）

**公式**：
```
z_t = (x_t − μ) / σ，其中 μ、σ 是全样本均值与标准差
```

**数学性质**：
- **前视偏差（致命）**：μ/σ 用全样本估计，含未来信息。
- **极值敏感（严重）**：σ 是二阶矩，对极端值敏感（方差被尾部
  主导）。一个 2008 年的极端值会把 σ 拉大，使正常波动期的
  z 值都偏小。数学上，样本标准差是平方损失的函数，对离群值
  的鲁棒性差（breakdown point = 0：单个极端值可以任意扭曲 σ）。
- **无界**：z ∈ (−∞, +∞)——不满足有界可比。
- 可解释 △（"偏离均值几个标准差"，但均值本身被极端值污染）。

**结论**：前视 + 极值敏感 + 无界，弃用。

### 3.1.3 robust z-score（备选方法）

**公式**：
```
z_t = (x_t − median(X_t)) / (1.4826 × MAD(X_t))
MAD = median(|x_i − median(X)|)
```

**数学性质**：
- **极值稳健（优点）**：中位数和 MAD 都是**秩统计量**——它们的
  breakdown point = 50%（最多一半数据被污染才失效），远优于均值/
  标准差的 0。单个极端值不影响中位数，对 MAD 的影响也有限。
- **1.4826 常数的来源**：MAD 在正态分布下不等于 σ，而是
  σ × Φ⁻¹(3/4) ≈ σ × 0.6745。乘 1/0.6745 ≈ 1.4826 后，MAD 在
  正态假设下**等于 σ**——使 robust z 与普通 z 在正态时数值可比。
  这个常数是"正态校准系数"。
- **前视**：用 expanding 版本的 median/MAD（只含 {X₁..X_t}）可消除
  前视——但展开版 MAD 需要足够样本才稳定（warm-up 更短，约
  6-12 个月即可，因为中位数比均值需要更少样本）。
- **无界（缺点）**：z 仍 ∈ (−∞, +∞)——跨变量不可比、不满足
  PCA 输入同质性（一个变量 z 值到 ±5，另一个到 ±1.5，尺度不同）。
- 可解释 △。

**结论**：稳健性好、warm-up 短，但**无界**破坏了跨变量可比性。
定位：备选方法（某些短样本场景可用），不作为罗盘主输入格式。

### 3.1.4 expanding/rolling 分位 → [-1,1]（首选）

**公式**：
```
P_t = (1/n_t) · Σ_{i≤t} 1{X_i ≤ X_t}      （宽松分位，含当期）
S_t = 2·P_t − 1 ∈ [−1, 1]
```
其中 n_t = {X₁..X_t} 中非缺失的个数，1{·} 是指示函数。

**数学性质**：
- **无前视（核心）**：P_t 只依赖 {X₁..X_t}——t 时刻的分位只用
  到 t 及之前的数据。这是定义保证的（求和只到 i≤t）。
- **极值稳健（核心）**：分位是**秩统计量**——极端值只影响它自己
  那一格的分位（接近 ±1），不影响其他值的相对排序。2008 年 PPI
  10% 会被映射到"当时的历史最高分位 ≈ +1"，但 2010 年的 5% 不会
  因为它而失真（5% 在含 10% 的历史里 rank 是 0.6 左右，含义清晰：
  "比 60% 的历史时期高"）。与 min-max 不同，**分位不受"单点极值"
  锚定**——因为它是逐点比较，不是求全局范围。
- **有界**：S ∈ [−1,1]——跨变量严格可比：PE 的 −0.5 与 M2 的
  −0.5 含义相同（都处于各自历史的 25% 分位）。PCA 输入同质。
- **可解释（核心）**：S = −1 历史极低 / 0 中性 / +1 历史极高——
  "PE 处于历史 80% 分位"是人话，比"PE 偏离均值 1.7 个标准差"
  直观得多。这是**罗盘最终输入格式**（v1.2 定案）。
- **含当期偏差**：P_t 把自己也算进"≤"计数（1{X_t ≤ X_t} = 1），
  而严格"前值分位"（只用 {X₁..X_{t−1}}）会给 P_t = 自身在历史
  中的位置。两者的差 ≤ 1/n_t——n_t ≥ 24 时 ≤ 4.2%，可忽略
  （且方向保守：含当期使极端值略微更极端，不产生虚假信号）。

**结论**：四要求全满足——无前视 ✓ 极值稳健 ✓ 有界可比 ✓ 可解释 ✓。
**首选**（v1.2 定案，回测实证支持，见 3.2.4）。

### 3.1.5 四个方法对比总表

| 判据 | min-max | 全样本 z | robust z | expanding 分位 |
|---|---|---|---|---|
| 无前视 | ✗（全样本极值） | ✗（全样本 μσ） | △（expanding 版可） | ✓（定义保证） |
| 极值稳健 | ✗（单点锚定） | ✗（breakdown=0） | ✓（秩统计量 50%） | ✓（秩统计量） |
| 有界可比 | ✓ | ✗ 无界 | ✗ 无界 | ✓ [−1,1] |
| 可解释 | △ | △ | △ | ✓（历史分位） |
| warm-up | 无 | 无 | 短（6-12 月） | 24 月（min_periods） |
| 结论 | 弃 | 弃 | 备选 | **首选** |

## 3.2 expanding 分位的三个数学细节

### 3.2.1 为什么"含当期"可以接受（偏差的数学上界）

严格的无前视分位有两种定义：
- **含当期**：P_t = rank(X_t in {X₁..X_t})/n_t（我们用的）
- **严格前值**：P_t = rank(X_t in {X₁..X_{t−1}})/(n_t − 1)

两者之差：含当期把 X_t 自身计入了"≤ X_t"的分子和分母各一次。
分子差 ≤ 1（X_t 至少排在自己前面），分母差 = 1。因此：
```
|P_含当期 − P_严格前值| ≤ 1/n_t
```
n_t = 24 时 ≤ 4.2%，n_t = 100 时 ≤ 1%。**偏差随历史增长而衰减，
且方向固定（含当期使值略偏极端），不产生虚假的"平滑/乐观"信号**。
工程上选择含当期（pandas 原生支持、向量化快），文档注明偏差上界。

### 3.2.2 min_periods=24（warm-up）的数学理由

**问题**：样本太少时，分位的"分辨率"不足。n 个观测的分位只能取
{n 个离散值}——n=6 时 P 只能取 0, 1/6, ..., 1（7 档，每档 16.7 个
百分点），n=24 时 25 档（每档 4%）。

**为什么 24**：
- 分位分辨率 1/n ≤ 1/24 ≈ 4%——"比 76% 的历史高"这样的说法在
  n=24 时有意义（档位粒度 4%）；
- 24 个月 = 2 年，覆盖至少一个完整的经济季度循环和多个发布周期；
- 与 Phase 2 的 INSUFFICIENT_HISTORY 语义一致（<24 个月历史 =
  样本不足）。

**warm-up 的实现**：expanding 窗口 min_periods=24——前 23 个观测
输出 NA（归一化面板的前 23 行没有值），从第 24 个观测开始输出。
这些 NA 在 missingness 层记为 INSUFFICIENT_HISTORY（第 2 章 10 类
缺失之一）。

### 3.2.3 为什么 expanding 而非 rolling（回测实证）

- **expanding**：窗口 = 全部历史 {X₁..X_t}。语义："这个值在**它
  所有历史**里处于什么位置"——这正是"历史极低/极高"的本意。
  参数随历史缓慢演化，稳定。
- **rolling(24)**：窗口 = 最近 24 个月。语义："这个值在**最近两年**
  里处于什么位置"——对短期波动敏感：2015 年牛市中 PE 连续 24 个月
  上行，rolling 分位会显示"PE 处于近两年最高"（+1），但按全历史
  看 PE 可能只是中等（+0.3）。rolling 分位**频繁触发极端值**，信号
  噪声大。

**实证**（第 7 章回测）：Compass 用 expanding 分位 → 2015-2026
Sharpe 0.16；改用 rolling 24 分位 → Sharpe 0.03（显著劣化，年化
从 4.09% 掉到 2.45%）。**回测数据证明了 expanding 的选择正确**——
v1.2"首选 expanding、rolling 备选"的定案获得样本外验证。

### 3.2.4 分位计算对 NA 的处理

- NA 不参与分位计算（pandas expanding 自动跳过缺失值）；
- 窗口计数 n_t 只统计非 NA 的观测；
- 输出保持 NA（归一化面板的缺失格与原始缺失格一一对应，加上
  warm-up 的 INSUFFICIENT_HISTORY）。

## 3.3 regime 分组分位（BY_FEATURE_REGIME）

### 3.3.1 为什么分组

第 2 章讲过：M1 2025 新口径、AFRE 五段口径——不同口径的值**不可
直接比较**。分位计算隐含假设"样本同质"（来自同一分布）。把新旧
口径混在一起算分位 = 把口径切换当经济变化（M1 2025 年初的"分位
跳升"其实是口径效应）。

**处理**：按 regime 分组，**组内各自 expanding 分位**（不跨断点）：
- M1 两段（M1_PRE_2025 / M1_2025_NEW）各自算分位；
- AFRE 五段各自算分位；
- 任何分析都看不到"跨口径的分位"。

### 3.3.2 实现：per-regime min_periods

分组分位需要每组独立 warm-up——但不同组的样本量不同，warm-up
可以按组设置（by_regime_percentile 支持 dict 参数）：
```python
min_periods = {"M1_2025_NEW": 12, "M1_PRE_2025": 24, ...}
```

### 3.3.3 样本不足的决策：M1 新口径段（临时放宽 12）

**问题**：M1 新口径从 2025-02 决策月才有值，到 2026-07 只有
18 个月 < 24（min_periods）。严格 warm-up 意味着 **2026-12 之前
"当前状态"没有 M1 分位**——流动性领先核心锚缺位（M1-M2 剪刀差
是流动性模块的关键输入）。

**选项与权衡**（2026-08-27 用户拍板的决策）：
| 选项 | 效果 | 代价 |
|---|---|---|
| A 严格 24 | 2026-12 前 M1 分位 NA | 当前状态缺流动性锚 |
| B NEW 段放宽 12 | 2026-01 起有值（12-18 个月样本） | 分位分辨率 1/12≈8%，粗糙但可用 |
| C NEW 段 robust z | 6-12 个月即可 | 与其余 83 变量格式不可比（PCA 输入混质） |
| D 借用 PRE 段基准 | 立即有值 | 跨口径污染（违背分组初衷） |

**决策**：M1 两变量（liq.m1_yoy / m1_m2_gap）NEW 段 min_periods
放宽到 **12**（B 方案）——因为 M1-M2 剪刀差是流动性领先核心锚，
"当前状态"需要它；12 个月样本的分位虽粗糙（分辨率 8%），但作为
**方向性指示**够用；且 **2026-12 满 24 个月后自然对齐**（粗糙是
暂时的）。C 被排除（破坏 PCA 输入同质性——第 5 章会看到 PCA 对
输入尺度敏感）。D 被排除（违背分组分位的初衷）。

**代价记录**：normalization_registry 中注明 M1 NEW 段 warm-up=12
（临时口径），2026-12 后重跑 step3_3 自然恢复 24。

### 3.3.4 样本不足的决策：AFRE 严格保持（接受短覆盖）

**问题**：AFRE 官方序列 2015-02 起 + 5 段 regime，其中 POST_2019 段
（2020-02~2023-01）只有 36 个月，warm-up 吃掉 23 个 → 该段只有
13 个有效分位；POST_2023 段 42 个月 → 19 个有效。合计 AFRE 归一化
只有 **32 个月**（2022-01 起）。

**为什么不像 M1 一样放宽**：
- 放宽 12 最多救回 POST_2019 段尾部 12 个月（2021-02~2021-12），
  收益很小；
- AFRE 是 Extended 变量（不是流动性核心锚——核心是 M1/M2/央行
  表），当前状态缺它的分位影响有限；
- 改单一 expanding（不分组）违背 Step 2.5 审核确立的 regime 分层
  决定，需走正式流程且口径污染风险高。

**代价记录**：AFRE 分位覆盖 2022+；Phase 4 Credit 因子用 AFRE 时
注意：2022 前用原始值做描述性分析，因子早期段由其他信用变量
（新增贷款/12 月滚动）主导。

**教学要点**：样本不足的决策框架 = ①信号重要性（核心锚 vs 扩展）
②放宽的收益（救回多少样本）③放宽的代价（分辨率/可比性）④是否
暂时性（满 24 后自然对齐）。M1 三个理由支持放宽，AFRE 三个理由
支持严格——同一个问题，不同变量不同答案。

## 3.4 试点验证：方法验证的方法论

### 3.4.1 为什么先试点（用户指示"先从小样本开始尝试"）

全量 84 变量之前，先拿 5 个代表变量（覆盖四类：水平值 PE、同比
CPI、regime 状态 M1、构造特征 EYG）验证方法实现是否正确——**先
小样本验证，再全量**。试点成本低（分钟级）、发现问题早（不用等
全量跑完才发现方法 bug）。

### 3.4.2 试点四关验证

1. **值域**：输出 ∈ [−1,1]（越界 = 实现 bug）
2. **分布**：分位映射后应近似均匀（四档计数接近均等）——但真实
   数据不必完美均匀（PE 近年在历史中位数附近密集是真实分布）
3. **regime 分组**：M1 PRE 段末值（2024-12）与 NEW 段首值（2025-01）
   应基于各自段内历史；NEW 段样本不足 → 诚实 NA
4. **无前视**：见 3.4.3

### 3.4.3 无前视验证的数学设计（假警报教训）

**验证思路**：修改历史某个值 → 重算分位 → 检查"修改之前的位置
是否受影响"。
- 正确预期：修改 t 时刻的值，**只影响 t 及之后**的分位（因为
  t 之前的位置窗口不含 t）；t 之前必须不变（无前视核心）。
- 如果 t 之前变了 → 实现有前视（用了未来数据）。

**第一次验证失败（假警报）**：把 2015-06 的 PE 从 16.11 改成
99999（极端值）→ 2015-07 之后的分位**没变** → 误判"有前视"？
**排查后发现是验证设计缺陷**：
- 16.11 → 99999 的替换，两者都大于后续值 13.82/11.69——在后续
  窗口里，13.82 的"≤13.82 计数"和窗口长度都不变（99999 > 13.82
  不贡献分子，窗口长度含它但 16.11 也是 ≥13.82）→ 后续分位自然
  不变。**这不是无前视的证据，是"替换值没有跨越阈值"**。
- 改成 1.0（低于后续值 13.82，跨越阈值）→ 2015-07 之后的分位
  立即变化（13.82 的 rank 从"只大于 16.11 之前的值"变成"还大于
  1.0"）✓；2015-05 及之前不变 ✓——验证通过。

**教学要点**：
- 无前视验证的替换值**必须跨越后续值**（从高于变成低于，或反向），
  否则后续窗口的秩统计不变，验证无效；
- 正确的判定三件套：**之前不变（无前视核心）+ 自身变 + 之后变
  （窗口传播正常）**；
- 假警报的教训：**先怀疑验证设计，再怀疑实现**——最小实验
  （5 个值的序列 + pandas expanding().rank() 对比）确认 pandas
  实现正确后，问题定位到验证脚本。

### 3.4.4 pandas expanding().rank() 的实现确认

用最小实验确认 pandas 的 `Series.expanding().rank(pct=True)` 语义：
- 输出[t] = X_t 在窗口 {X₁..X_t} 内的升序分位（含当期）；
- 位置 0,1 不受修改位置 2 影响（无前视）；位置 3,4 受影响（窗口
  传播）——**与数学定义完全一致**，pandas 实现正确。

## 3.6 输出解读：怎么读归一化值

### 3.6.1 S 值的语义

S_t ∈ [−1,1] 读作："该变量在 t 时刻处于**它自己历史**的什么位置"：
- **S = −1**：历史极低（比过去任何时候都低——或接近）
- **S = 0**：中性（历史中位数附近）
- **S = +1**：历史极高
- S = 0.5：高于 75% 的历史观测

**注意**：分位是"相对自己的历史"，不是"绝对好坏"。同一 S 值
在不同变量间**可比**（都是各自历史的 75% 分位），但经济含义
由变量本身决定（PE 高位 = 贵；M2 高位 = 宽松）。

### 3.6.2 真实读数举例（2026-07）

| 变量 | 归一化值 | 解读 |
|---|---|---|
| PE_TTM | +0.444 | 处于历史 ~72% 分位——估值偏贵但不极端 |
| CPI 同比 | −0.437 | 处于历史 ~28% 分位——通胀偏弱（通缩压力） |
| M1 同比 | −0.222 | 处于历史 ~39% 分位——流动性活性偏弱 |
| AFRE（社融） | −0.952 | 处于 2022 以来历史 ~2% 分位——信用扩张极弱 |
| 宏观状态 | −0.229 | 8 因子等权合成后处于历史 ~39% 分位——偏冷 |

这些读数是第 6 章条件分布分桶的直接输入（S 值 → 三分桶 → 桶内
收益分布）。

### 3.6.3 归一化值的三个用途（后续章节预告）

1. **PCA 输入**（第 4 章）：[-1,1] 有界同质 → 8 模块因子可解
2. **条件分布分桶**（第 6 章）：S 值三分桶 → 桶内未来收益分布
3. **Compass Score 合成**（第 6 章）：估值分位 × 0.7 + 宏观 × 0.3
   → 仓位信号（第 7 章回测）

## 3.7 本章小结

- **归一化四要求**：无前视、极值稳健、有界可比、可解释——min-max
  和全样本 z 因前视+极值敏感弃用，robust z 无界（备选），
  **expanding 分位四要求全满足（首选）**；
- **expanding 分位的数学**：P_t = 历史秩占比（只含过去+当期）、
  含当期偏差 ≤1/n、min_periods=24 保证分位分辨率 ≥4%、expanding
  优于 rolling（回测实证 Sharpe 0.16 vs 0.03）；
- **regime 分组分位**：不跨口径算分位；M1 NEW 段临时放宽 12
  （核心锚 + 暂时性 + 方向够用），AFRE 严格 24（扩展变量 + 救回
  有限 + 违背审核）——样本不足的决策框架是"重要性 × 收益 × 代价
  × 暂时性"；
- **试点方法论**：先 5 变量四关验证再全量；无前视验证的替换值
  必须跨越阈值（假警报教训：先怀疑验证设计再怀疑实现）；
- **产物**：normalized_panel（223×84，越界 0）+ normalization_
  registry（84 行可审计）。
