**每个环节为什么存在**（一句话版）：
- 采集：没有变量就没有研究——但变量要承载假说（不是堆数据）；
- 清洗：没有 PIT 对齐，回测就是前视的假成绩；
- 归一化：没有 [-1,1] 分位，变量量纲不同无法比较、无法进模型；
- 因子：没有 PCA，84 个共线变量会让模型过拟合且无经济结构；
- 领先滞后：没有它，不知道"关系"是领先还是同步、是真的还是
  重叠样本的假象；
- 条件分布：没有它，只有"有关系"的抽象结论，没有"该配多少仓"
  的可操作答案；
- 回测：没有它，"规则有效"就只是样本内拟合的自说自话。

## 8.1 关键发现汇总

### 发现 1：估值是长期收益最强的预测变量（主信号）

**证据链**（三条独立线汇聚）：
1. **长期相关**：估值分位 × 未来 3/5/10 年收益 = −0.59/−0.67/−0.76，
   block bootstrap 全显著、随持有期单调增强；
2. **平稳性**：log(PE) 本身是 I(0)——估值有引力中心，不会随机
   游走（第 5 章 5.5.1）；
3. **协整**：价格与估值、利率、估值差三配对均存在长期均衡
   （95% 秩=1），VECM 回归速度慢（3-10 年尺度）。

**分布级呈现**（第 6 章条件分布）：便宜→贵，36 月年化中位
+11.6%/+6.1%/−3.0%（全持有期单调）；**贵桶 36 月亏损概率 54%**。

**投资含义**：估值是"长期仓位"的主锚——便宜时重仓、贵时轻仓，
这是均值回归的直接应用。**不是短期择时工具**（回归慢），是
3-10 年尺度的仓位中枢信号。

### 发现 2：宏观状态在估值之外提供稳定增量（微调信号）

- 单独加利率/流动性/信用因子：无 OOS 增量（噪声/信息重叠）；
- **宏观因子组合**（增长/通胀/居民/风险/宏观状态）：OOS RMSE
  改善 +30.4%；分时段两段稳定（2015-19 +3.4%、2020-26 +21.3%）；
- PIT 滞后检验通过（滞后 2 期 Sharpe 反而更好）——不依赖修订前视。

**投资含义**：宏观状态是"微调"——过热时降低风险暴露（热桶收益
低），但不足以单独决定仓位。Compass 用 0.3 权重给它（先验），
实证方向一致。

### 发现 3：规则仓位显著改善风险特征（保险属性）

2015-2026：年化 4.09% vs 满仓 4.65%（−0.56pp 保费），但波动
−36%（20.2%→13.0%）、MDD +16pp（−40%→−23%）、Sharpe/Sortino/
Calmar 全面提升、换手月均 5.1%。熊市保护显著（2016/2018/2022
各 +8~10pp），牛市略落后（设计特征）。

**投资含义**：罗盘是"长期仓位配置 + 熊市保险"，不是"择时超额
工具"。它的价值是让投资者**拿得住**（波动减半、回撤减半）——
拿得住，长期复利才成立。

### 发现 4：否定性结论（同样重要）

- **M1-M2 剪刀差"领先 6-9 个月"候选假说未复现**（因子层面：
  滞后扫描弱、Granger 不显著、长期 60/120 月 bootstrap 不显著）；
- 宏观状态 60 月视角 bootstrap 不显著（10 年显著）——宏观信号是
  "长周期微调"；
- 利率/流动性/信用**单独**无 OOS 增量（组合才有效）。

**投资含义**：不要把未经验证的"市场传说"（剪刀差领先）写进规则；
否定性结论保护了规则的真实性（只用了被验证的信号）。

## 8.2 这些发现意味着什么（综合）

1. **A 股长期回报可预测的部分主要是"估值回归"**：市场短期是投票机
   （情绪/流动性驱动，噪声大），长期是称重机（估值回归，可预测）。
   我们的数据（−0.76@10 年、协整慢回归）与 Campbell-Shiller 经典
   文献一致——**中国股市并不特殊**；
2. **宏观状态是"温度计"不是"方向盘"**：它告诉我们经济冷热
   （过热后收益低），但方向盘（仓位中枢）由估值决定——这符合
   直觉：基本面定价值，估值定价格与价值之间的距离；
3. **逆向投资的数学基础**：贵的时候买（追高）在 36 月尺度上有
   54% 概率亏损——"低买高卖"不是道德说教，是条件分布的直接
   结论；
4. **保守是特性不是缺陷**：规则牺牲 0.56pp 年化换一半的波动和
   回撤——对长期投资者（能拿住）这才是最优解（复利的前提是
   不被中途淘汰）。

## 8.3 当前状态与建议（2026-07）

**Compass Score = +0.399 → 历史 80% 分位 → 偏高档**

| 分项 | 读数 | 含义 |
|---|---|---|
| 估值因子 | +0.88（偏高） | PE/PB 历史高位，市场贵 |
| 信用因子 | −0.95（收缩） | 社融/贷款放缓，信用紧 |
| 居民信心 | −1.13（低迷） | 消费者信心历史低位 |
| 风险因子 | +1.16（高波动） | 波动/杠杆活跃 |
| 宏观状态 | −0.23（偏冷） | 综合状态中性偏弱 |

**仓位建议：55-70%（偏高档 → 偏低/中性仓位区间）**：
- 依据 1：高估值桶 36 月年化中位 −3.0%、亏损概率 54%——当前
  估值偏高意味着未来 3 年期望收益为负概率高；
- 依据 2：信用收缩 + 信心低迷是宏观逆风（不支持满仓）；
- 依据 3：但宏观状态未到极热、估值未到极端泡沫档（PE 分位 ~72%
  不是 95%）——不是清仓时点，保留中性偏低的暴露；
- **操作含义**：新资金分批建仓的节奏放慢；已有持仓不追加；
  等待估值回落到历史中位以下（Compass < 0）再提高仓位。

**注意**：这是**研究框架的读数**，不是投资建议——最终决策结合
个人风险承受能力与资金期限（局限见 8.4）。

## 8.5 局限与撤回条件（可操作版本）

| 局限 | 缓解 | 撤回/监控条件 |
|---|---|---|
| PIT 偏误（修订终值） | 滞后 2 期检验通过（Sharpe 反而更好） | 每月检查：滞后版 Sharpe 恶化 >0.1 |
| 重叠样本（长期收益） | block bootstrap CI 判定显著性 | 永远以 CI 为准，不信名义 p |
| 小样本（223 月/11 年） | 分时段增量 + walk-forward | Model4 增量 <1% → 退回 Model1 |
| 估值均值回归失效 | 反向论证 #1 | 条件分布不再单调 → 撤估值权重 |
| 宏观状态合成失真 | 载荷漂移监测 + 增量检验 | 漂移 >0.8 或增量不稳定 → w_macro→0 |
| 牛市收益惩罚 | 反向论证 #5 | 连续 3 年跑输 >15pp → 调整规则 |
| 数据缺口 | 覆盖标注 + 补足清单 | 核心 CPI/PPIRM 2021 前、股息率等补足后重跑 |

## 8.6 使用指南：怎么用这个系统

### 8.6.1 数据更新（每月）

1. 新一期宏观数据发布（CPI/PMI/M2/社融等）→ 追加到 data_raw；
2. 重跑 Phase 2-7 脚本（全部可复跑，输入 02 输出 03-07）：
   ```
   step3_3（归一化）→ step4_2（因子）→ step5_1~5_3（领先滞后）
   → step6_1~6_3（条件分布/Compass）→ step7_1~7_3（回测/检验）
   ```
3. 读取最新 Compass Score 与仓位档；
4. 检查撤回条件是否触发（估值单调性/增量稳定性/载荷漂移）。

### 8.6.2 调仓纪律

- **季度/半年检查一次即可**（信号是慢变量，月频调仓没有必要）；
- 五档仓位区间 40%-100%，每次调整不超过 1 档（避免频繁大动）；
- **逆向执行**：Compass 高（贵）时降仓需要纪律——这正是多数人
  做不到的（第 7 章分年表显示 2017/2019 牛市中降仓"踏空"了最后
  一段，但也正是 2018/2022 少亏的来源）。

### 8.6.3 可视化复核

- 08_可视化（localhost:8501）可直观查看：滚动相关、热力图、
  前向收益散点、条件分布——用于人工复核机器结论；
- 导出公众号风格配图（暖白底/红涨绿跌）用于记录与分享。

## 8.8 结语：这个项目教给我们什么（方法论层面）

除了投资结论，这个项目本身是一次完整的研究方法论训练：

1. **先有经济逻辑，再跑统计**（v1.2 第 1 条）：每个变量承载假说
   （第 1 章理论地图），不是数据驱动式地"找关系"；
2. **无前视是底线，不是选项**：PIT 对齐（第 2 章）、expanding
   分位（第 3 章）、无前视回测（第 7 章）——每一层都在防同一
   个错误（用未来信息）；
3. **方法选择要有数学理由**：为什么 expanding 分位（秩统计量/
   有界/无前视）、为什么 PCA（方差最大/正交/经济标签）、为什么
   block bootstrap（保留自相关）——每个"为什么"都能说清楚；
4. **诚实的否定与诚实的局限**：M1-M2 假说未复现就报告未复现；
   PIT 偏误检验做了；过拟合风险标注了；撤回条件写好了——**研究
   的价值在于可证伪，不在于"证明自己对"**；
5. **可复现、可审计、可教学**：脚本可复跑、RECORD 每步八段、
   处理说明培训格式——这个项目的"副产品"（方法论与文档）也许
   比投资结论本身更持久。
