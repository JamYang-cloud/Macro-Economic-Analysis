# 第 4 章：模块因子详解——PCA 的数学原理、为什么用它、载荷怎么读

> 本文档是《宏观股市罗盘》教学序列的第 4 章。第 3 章把 84 个变量
> 归一化成了 [-1,1] 的分位值；但 84 个变量太多、彼此重叠（M1/M2/
> 社融都在讲流动性，PE/PB/EYG 都在讲估值）。本章讲**降维**：把同一
> 经济模块里的变量用 PCA 合成一个**有经济标签的因子**（增长因子、

> 表示"当前宏观处于历史什么位置"。
>
> 读完本章，你应该能回答：为什么用 PCA 而不是简单平均？特征分解

> 而不是全变量一个 PCA？滚动窗口的符号对齐是什么问题？载荷漂移
> 告诉我们什么？以及——8 个因子的实际载荷该怎么解读。

## 4.0 为什么需要因子合成

第 3 章产出了 84 个归一化变量，但**直接拿 84 个变量进模型有三个问题**：

1. **维度灾难**：223 个月样本、84 个变量——回归/模型的参数个数接近
   样本量，过拟合风险极高（第 6 章的 Benchmark Ladder 会看到 9 特征
   已经接近极限）。
2. **多重共线性**：M1 和 M2 高度相关、PE 和 PB 高度相关——放进同一
   个回归，系数估计方差爆炸（矩阵接近奇异）。
3. **无经济结构**：84 个变量是"平铺"的，模型不知道"这 5 个变量是
   一类（流动性）"——它会把共线变量当成独立信号重复计算。

**因子合成的目标**：把每个经济模块的多个变量压缩成**一个正交的、
有经济标签的因子**——8 个因子替代 84 个变量，且每个因子能说清楚
"它代表经济的哪个侧面"。这就是 v1.2 的"模块内 PCA"路线。

## 4.1 为什么用 PCA（而不是简单平均）

### 4.1.1 平均法的缺陷

一个直觉方案：把模块内变量直接平均（比如流动性因子 = (M1+M2+社融)
/3）。数学上平均 = 给每个变量**固定等权 1/k**。问题：

- **假设了权重相等且方向一致**：真实数据里变量的重要性不同——
  通胀因子中 PPI 的波动远大于 CPI（工业品价格周期更剧烈），平均
  会稀释 PPI 的信息；
- **假设了变量方向一致**：估值模块里 PE/PB 与 EYG **天然反向**
  （PE 高=贵，EYG 高=便宜）——直接平均会把反向信息互相抵消成
  接近 0 的无意义值；
- **没有利用协方差结构**：平均忽略了"变量间相关多少"——两个
  完全同源的变量（PE 和 PB）各占一票，等于重复计票。

### 4.1.2 PCA 的核心思想

**PCA（主成分分析）做的事情：在变量空间里找"方差最大的方向"**，
把 k 个相关变量压缩成少量"主成分"——每个主成分是变量的线性组合
（加权平均），但**权重不是等权，而是由数据的协方差结构决定**：
权重让主成分的方差最大化（信息最大化），并且各主成分之间正交
（互不重复）。

数学上：主成分 w₁ = argmax Var(wᵀX)，约束 ||w||=1——**在单位球上
找投影后方差最大的方向**。这个方向就是数据"最会变"的方向，也
就是信息最集中的方向。

### 4.1.3 为什么用相关矩阵而非协方差矩阵

PCA 可以对协方差矩阵或相关矩阵做特征分解：
- 协方差矩阵：变量的尺度影响结果（方差大的变量主导）；
- 相关矩阵：先把每个变量标准化（除以自己的标准差）再算协方差
  ——**所有变量尺度统一，PCA 结果与尺度无关**。

我们的输入已经是 [-1,1] 分位（第 3 章归一化），尺度天然一致，
用相关矩阵等价于协方差矩阵——但**原则上**讲：归一化后变量方差
接近（分位值方差 ≈ 1/3），两者差异很小。实现上用相关矩阵
（pandas corr()，pairwise 处理缺失）。

## 4.2 PCA 的数学原理（特征分解）

### 4.2.1 特征分解

设 X 是 n×k 的变量矩阵（n 个月、k 个变量），相关矩阵 R = corr(X)
是 k×k 对称半正定矩阵。**特征分解**：

```
R v_j = λ_j v_j,  j = 1..k
```

- v_j 是**特征向量**（k 维单位向量）——表示一个"方向"（变量空间
  里的一个组合权重）；
- λ_j 是**特征值**（非负实数）——表示数据沿 v_j 方向的方差大小。

对称矩阵的性质保证：特征向量两两正交（v_iᵀv_j = 0, i≠j），
特征值按大小排列 λ₁ ≥ λ₂ ≥ ... ≥ λ_k ≥ 0。

### 4.2.2 解释方差与主成分选择

**总方差** = 所有特征值之和 = Σλ_j（相关矩阵的迹 = k，因为对角线
都是 1）。第 j 个主成分解释的方差比例：

```
explained_j = λ_j / Σλ_j
```

**累计解释方差**（cumulative explained variance）：
```
cumvar_p = (λ₁ + ... + λ_p) / Σλ_j
```

**为什么选 80%**（v1.2 定案）：
- 目标是"用最少的主成分保留主要信息"——80% 是信息-维度的平衡点：
  - 太高（95%+）：几乎要保留全部 k 个主成分，没有降维；
  - 太低（60%）：丢了太多信息，因子不能代表模块；
  - 80%：多数模块 1-3 个主成分即可达到（见 4.6 实际数字），
    是经验上"信息主要部分"的合理阈值。
- **注意**：80% 是启发式（heuristic），不是统计检验——它基于
  "80/20 法则"（少数主成分解释大部分方差）的实证普遍性。选择
  后要用经济可解释性复核（载荷是否合理），不是机械接受。

### 4.2.3 载荷与得分

- **载荷（loading）**：特征向量 v_j 的分量——第 j 个主成分对每个
  变量的权重。v_j[i] 表示变量 i 在主成分 j 中的贡献（|v| 大 =
  贡献大，符号表示方向）。
- **得分（score）**：主成分在每个月上的值 = 变量值 × 载荷：
  ```
  score_j(t) = X(t) · v_j = Σ_i X_i(t) · v_j[i]
  ```
  得分序列就是"这个因子随时间怎么变"——它就是我们后续研究用的
  因子序列（如 Liquidity_PC1）。

**单位圆约束**：||v_j|| = 1（特征向量单位化）——载荷的平方和 = 1。
所以载荷的**绝对大小**不直接等于"重要性"，要结合解释方差看：
载荷 0.7 的变量在 PC1 里贡献大（0.7² = 49% 的 PC1 方差来自它）。

### 4.2.4 缺失处理（pairwise）

我们的输入有缺失（短覆盖变量、warm-up 期）：
- 相关矩阵用 **pairwise** 计算（每对变量用各自共同非缺失的月份）——
  不因为一个变量短历史而牺牲所有配对的样本；
- 得分计算时缺失月份填 0（= 中性，因为归一化值均值 ≈ 0）——代价
  是缺变量月份的得分略失真，但保持序列完整；registry 记录每月的
  参与变量数（可审计哪些月是"部分信息"）。

## 4.3 为什么按 8 个模块分开 PCA（而不是全变量一个 PCA）

### 4.3.1 全变量 PCA 的问题（v1.2 弃用）

早期方案是"全部 84 变量 → 一个 PCA → 事后给主成分贴标签"。问题：
- **主成分无法解释**：84 个变量的第一主成分是"所有变量的某种混合"
  ——它可能同时含 M2、PE、金价，无法说清它代表什么经济含义；
- **经济标签是事后贴的**：统计先跑、含义后编——这是"先射箭再画靶"，
  不符合"先有经济机制再做模型"的方法论原则（v1.2 第 1 条）；
- **跨模块混合**：流动性变量和估值变量混在同一个主成分里，后续
  无法单独研究"流动性的影响"。

### 4.3.2 模块内 PCA 的优势

**先按经济含义分模块，模块内 PCA**：
- 每个主成分**天然有经济标签**（增长因子 = 增长模块的 PCA 结果，
  载荷全是增长变量）；
- 因子数量可控（8 个模块 → 8 个因子，每个取 PC1 为主）；
- 后续研究可以单独考察"流动性因子的领先性"、"估值因子的均值
  回归"——因子语义清晰；
- 符合 v1.2 方法论：**经济逻辑先行（分模块），统计工具随后（PCA
  压缩）**。

### 4.3.3 模块映射的决策（用户拍板）

每个模块选 3-4 个代表变量（第 1 章讲过每个变量的含义），选择
原则（2026-08-27 用户拍板推荐版）：

| 模块 | 变量 | 选择理由 |
|---|---|---|
| Growth | gdp_yoy, ip_yoy, pmi, retail_yoy | PLAN 核心 4 类；PMI 分项覆盖短跳过 |
| Inflation | cpi_yoy, ppi_yoy, enterprise_goods | PPI 主导 + 长覆盖；核心 CPI/PPIRM 仅 66 个月跳过 |
| Liquidity | m2_yoy, m1_yoy, cbb, fr007_p90 | 货币量 + 央行表 + 资金利率（DR007 用 FR007 特征代理） |
| Credit | new_loan, loans_12m, tsf_flow | 信贷流量 + 12 月滚动 + 社融增量；AFRE 覆盖短跳过 |
| Valuation | pe_ttm, pb, eyg | 估值锚 + 相对利率的便宜度 |
| Rates | cn10y, cn2y, term_spread | 10Y + 短端 + 期限利差（PLAN 三要素） |
| Household | consumer_confidence, consumer_satisfaction, deposit | 信心 + 存款；income 覆盖短跳过 |
| Risk | vol12(派生), hs300_volume, market_balance | 波动率 + 成交 + 杠杆（PLAN 三要素） |

**两个决策点**：
1. **覆盖短的变量跳过**（核心 CPI/PPIRM/AFRE/income）——进 PCA 会
   让因子窗口缩水（PCA 需要整个模块的共同窗口），短变量是"少数派"
   却会拖累全局；留作单变量分析。
2. **Risk 波动率派生**：hs300_tri 月度收益的 12 个月滚动标准差 →
   expanding 分位归一化（**必须用原始序列算收益**，不能用归一化
   值算 pct_change——[-1,1] 分位没有"收益"语义）。派生过程本身
   无前视（rolling 12 月只含过去 + expanding 分位只含过去）。

## 4.4 滚动窗口与符号对齐

### 4.4.1 为什么滚动窗口（36 → 60-84 个月）

**v1.2 修正**：早期用 36 个月滚动窗口，审核发现载荷不稳定——为什么？
- 样本协方差矩阵的估计质量依赖 n（样本数）与 k（变量数）之比；
- 36 个月对 k=3-4 的模块虽然"够秩"，但**载荷估计的方差大**——
  协方差矩阵的采样噪声在短窗口下显著（协方差估计量的收敛速度
  是 1/√n，n=36 时噪声 ~17%）；
- 60-84 个月（5-7 年）窗口：覆盖完整的经济周期片段，载荷估计
  更稳（1/√60 ≈ 13%，1/√84 ≈ 11%）。

**滚动 vs 静态**：静态全样本 PCA 给"平均载荷"（基准）；滚动窗口
PCA 给"载荷如何随时间演化"（漂移诊断）。两者互补：静态是基准，
滚动看稳定性。

### 4.4.2 符号对齐（sign alignment）：一个必须处理的数学细节

**问题**：特征向量 v 与 −v **数学上等价**——都是同一主成分的方向
（Σ(−v) = −Σv = −λv = λ(−v)，−v 也是特征向量）。特征分解算法
（LAPACK/eigh）返回的符号是任意的（取决于数值实现）。

**后果**：滚动窗口 A 算出 PC1 载荷 [0.5, 0.6, 0.6]，窗口 B 算出
[−0.5, −0.6, −0.6]——两者是**同一个因子**（只是方向反了），但
不处理的话，载荷漂移图会看到"载荷在 +0.6 和 −0.6 之间跳变"，
**完全无法判断变量权重是否稳定**；因子得分序列也会符号翻转
（流动性因子一会儿 +0.5 一会儿 −0.5，含义错乱）。

**对齐方法**：以静态全样本载荷为基准 v_ref，对每个滚动窗口的
载荷 v_win：
```
if v_ref · v_win < 0:  v_win ← −v_win   （点积为负 → 翻转）
```
点积 v_ref·v_win = ||v_ref||·||v_win||·cosθ——θ 是两个方向夹角。
夹角 < 90°（点积 > 0）→ 方向一致，不翻；> 90° → 反向，翻转。

**教学要点**：符号对齐是 PCA 应用中的经典"隐性坑"——统计上 v
和 −v 合法，应用上必须统一方向才能解释。任何"滚动/分块 PCA +
比较载荷"的研究都会遇到，必须显式处理。

### 4.4.3 expanding 基准

除滚动 60 月外，还计算 expanding（起点到 t）载荷作为第二基准：
- 滚动 60 月：反映"最近 5 年"的传导结构；
- expanding：反映"全历史累积"的传导结构；
两者对照可看：漂移来自"最近 regime 变化"还是"长期趋势"。

## 4.5 载荷漂移：传导机制的时间稳定性

### 4.5.1 载荷的经济含义

载荷 = 模块内变量对因子的"权重"——它度量**传导机制**：流动性
因子中 M1 载荷 0.71 意味着"M1 是流动性状态的主要体现"；如果
载荷随时间漂移（M1 载荷从 0.7 掉到 0.3），说明**M1 对流动性的
代表性在变化**（经济结构/货币框架变了）。

### 4.5.2 实际结果（Phase 4 实测）

| 模块 | 载荷最大漂移 | 稳定性 | 含义 |
|---|---|---|---|
| Valuation | 0.01-0.02 | 极稳 | PE/PB/EYG 的关系几十年不变——价值逻辑稳定 |
| Rates | 0.06-0.27 | 很稳 | 利率期限结构关系稳定 |
| Household | 0.05-0.39 | 较稳 | 信心-存款关系基本稳定 |
| Growth | gdp_yoy 1.05 | **漂移大** | GDP 与 IP/PMI/社零的关系随结构转型变化（2015 后服务业占比上升） |
| Liquidity | m1_yoy 1.20 | **漂移大** | M1 对流动性的代表性随货币框架变化（2025 口径修订 + 2015 年 M1 高增异常） |
| Risk | vol12 1.17 | **漂移大** | 波动-成交-杠杆的关系随杠杆周期变化（2015 杠杆牛 vs 2018 去杠杆） |

### 4.5.3 漂移的用途

- **诊断**：漂移大的模块（流动性/风险）——它的因子"今天代表什么"
  可能和 10 年前不同，下游分析要谨慎（第 6 章增量检验分时段看
  宏观因子的稳定性，就是对这个问题的回应）；
- **敏感性**：载荷漂移是反向论证（第 7 章）里"宏观状态合成失真"
  反例的证据基础——撤回条件之一就是"载荷漂移超阈值（|Δ|>0.8）"；
- **不修**：漂移是**真实的经济结构变化**，不是统计错误——我们不
  "修正"它，而是记录它、监测它、在结论里说明它。

### 4.6.1 逐模块结果表

| Inflation | 2 | 99% | 71% | cpi 0.35, ppi 0.65, eg 0.67 | **PPI 主导**的通胀因子——工业品价格周期（PPI 波动 > CPI） |

### 4.6.2 重点解读 1：Liquidity 的 cbb 负载荷（真实结构，非 bug）

Liquidity PC1 载荷：M2 +0.53、M1 +0.71 为正，**央行资产负债表
（cbb）−0.42、FR007 −0.21 为负**。为什么央行表扩张与 M1/M2 高增
**反向**？

真实经济机制：2014 年前中国基础货币投放靠**外汇占款**（顺差 →
央行购汇 → 央行表扩张 → 基础货币增加 → M2 扩张），两者同向；
2014-2016 年**资本外流**导致外汇占款下降、央行表**收缩**，但央行
通过降准降息+再贷款工具**维持 M1/M2 高增**（M1 增速 2015-2016 冲到
20%+）——出现了"央行表收缩但货币高增"的时期。数据里 cbb 与
M1/M2 的负相关就是这段历史的真实记录。

**解读**：Liquidity PC1 = "货币扩张（M1/M2 高）但央行表不扩张
（甚至收缩）"的状态——这其实是**央行主动宽松（降准/工具投放）**
的特征：表外工具替代表内投放。载荷的符号结构告诉我们传导机制：
**不是 bug，是数据说话**。

### 4.6.3 重点解读 2：Valuation 的 eyg 反向（贵度因子）

Valuation PC1：PE +0.58、PB +0.58、**EYG −0.58**。为什么 EYG 与
PE/PB 反向？

- PE/PB 高 = 市场**贵**（盈利收益率 1/PE 低）；
- EYG = 1/PE − 10Y 利率 = **便宜度**（EYG 高 = 股票相对债券便宜）；
- 所以"贵"与"便宜度"天然反向——PC1 载荷完美捕捉了这个经济关系。

**PC1 的含义**：贵度因子（高 = 贵）。因子得分高 → 市场估值贵 →
第 6 章将实证"贵 → 未来长期收益低"。载荷的符号结构本身就是一个
"经济先验被数据确认"的例子。

### 4.6.4 其他模块的符号一致性

- Growth 全正：经济扩张 = 各增长变量同向上行 ✓（载荷符号一致是
  "模块同质性"的体现——如果某变量载荷与其他反向且无经济理由，
  要怀疑数据问题）；
- Inflation PPI 0.65 > CPI 0.35：PCA 自动给波动大的变量更大权重
  （信息更多）——这正是"平均法"做不到的；
- Household deposit −0.39：信心高时存款增速低（敢花钱）——预防性
  储蓄的反向体现；
- Rates spread −0.44：利率水平高时期限利差往往收窄（加息周期
  短端上行更快）——期限结构理论的实证。

## 4.7 宏观状态合成

### 4.7.1 合成方法

```
macro_state(t) = 等权平均(8 个模块 PC1 的标准化 z 值)
                → expanding 分位归一化到 [-1,1]
```

- **先标准化**：各模块 PC1 的尺度不同（解释方差不同 → 得分幅度
  不同），先转 z 再平均，避免方差大的模块主导；
- **等权**：v1.2 定位为 **structural prior（先验假设）**——没有
  先验理由认为某个模块更重要，所以等权起步；**权重差异留给
  第 6 章 Benchmark Ladder 用数据验证**（如果某模块 OOS 无改善，
  w→0）；
- **expanding 分位归一化**：与第 3 章同语义（[-1,1]、无前视），
  宏观状态直接可读："当前宏观综合状态处于历史什么位置"。

### 4.7.2 为什么 8 个模块合成一个数

宏观状态是"综合读数"——回答"经济整体冷还是热"。单个模块因子
（如流动性）是分项，宏观状态是总分。用途：
- 第 5 章：宏观状态与未来收益的领先滞后（Granger 显著）；
- 第 6 章：宏观状态分桶的条件分布（过热桶收益低）；
- 第 6 章：Compass Score 的 0.3 权重成分。

### 4.7.3 当前读数（2026-07）

宏观状态 = **−0.229**（历史 ~39% 分位，偏冷）——与分项一致：
信用收缩（−0.95）、居民信心低迷（−1.13）、增长偏弱（−0.38），
对冲了估值偏高（+0.88）与风险活跃（+1.16）。综合"冷"但未到
极冷。

## 4.8 本章小结

- **为什么 PCA**：平均法假设等权+同向（PE/PB/EYG 反向会抵消），
  PCA 让数据决定权重（方差最大方向）、主成分正交（信息不重复）；
- **数学**：相关矩阵特征分解 Rv=λv、解释方差 = λ/Σλ、80% 阈值是
  信息-维度平衡的启发式、载荷 = 特征向量分量、得分 = X·v；
- **为什么分模块**：全变量 PCA 无法解释（事后贴标签），模块内
  PCA 因子天然有经济标签——经济逻辑先行；
- **滚动 60 月 + 符号对齐**：短窗口载荷估计噪声大（1/√n）；
  v 与 −v 等价必须用点积对齐；expanding 作第二基准；
- **载荷漂移**：Valuation/Rates 稳定（传导机制不变），Liquidity/
  Risk/Growth 漂移大（货币框架/杠杆周期/结构转型）——记录并监测，
  不"修正"；
- **实际载荷全可解读**：Growth 全正、Inflation PPI 主导、Liquidity
  cbb 负（央行缩表 vs M1 高增的真实结构）、Valuation eyg 反向
  （贵度因子）、Household deposit 负（预防性储蓄）；
- **宏观状态** = 8 因子等权（先验）→ expanding 分位 [-1,1]，
  当前 −0.229 偏冷。

Granger 因果的数学（VAR 框架、F 检验）、block bootstrap 的原理
