## 关键口径

- **时间轴**：decision_month = 决策月首；月度面板 2008-01 起（宏观月度可得性），长史变量经 JP-HIST 年度层延伸至 1978。
- **四组分类**：宏观 / 货币金融 / 资本 / 居民（catalog 与 registry 的 group 字段）。
- **缺失纪律**：源缺失一律登记 NA reason（缺失矩阵），不插值；PIT 层记录每点可用性。
- **价格指数**：沪深300 全收益（TRI/价格/ETF 代理）为市场基准；红涨绿跌口径贯穿报告与可视化。

## 与其他目录关系

- `visualization/data_snapshot_v2/` = 本目录所选文件的只读展示投影（程序唯一数据源，附 SHA manifest）。
- 分析结论与逐章方法：`reports/cn/`（深度总结报告 + 教学文档）。
