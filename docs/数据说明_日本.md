# 数据说明 · 日本（JP）

日本侧为**口径冻结**的官方研究数据副本（JP1.7/JP1.8 冻结语义），文件均在 `data/japan/`。

- `data_snapshot/`：冻结数据（程序只读此层；本仓库为发布副本，含 manifest CSV 可校验）
- `early_history/`：COMPARISON-ONLY 早期段（1949 起，仅用于与近期对比，禁入建模）
- `crosswalk_v1.csv`：中日 M3 概念对齐表（concept_family / CN↔JP 变量 / 可比性 A/B/C / 归一化建议）

## early_history/（6 序列，比对专用）

nikkei225 全史日度（1949+）、公定歩合贴现率（1953+）、零售销售环比（1955+，镜像）、制造业 PPI（1960+，镜像）、
実質 GDP FY 增速（1955+，内閣府）、65 岁以上人口占比（1950+）。这些序列仅用于「日本早年长史」形态展示。

## 来源与纪律

- 来源通道：BOJ（政策利率/FFA/基础货币）、e-Stat（CPI 2025 基准）、MLIT（建筑/地价）、内閣府（GDP）、
  FRED（镜像：NIKKEI225/CPI/PPI/利率）、BIS（信贷/房价）。镜像序列均带 `(镜像, 停更年)` 标注。
- **PIT 语义**：vintage/决策口径分离——镜像序列仅作对照（vad=collection 禁回测），官方序列按决策网格口径。
- **与可视化关系**：M2 日本模块统一变量池（月度状态 10 + PIT 33 + 早期 5 + 日经 + 补充数据季度 11 + 年度 8）即读本层；
  M3 中日对比的 JP 侧取数 = 本层池 ∪ early ∪ 年度/季度补充数据。
- 分析结论：`reports/jp/`（JP2 宏观-股市关联分析报告）。
