# Macro-Economic-Analysis ｜ 宏观股市罗盘（中国 + 日本 + JP-HIST 对比）

中日两国「宏观 — 股市关联与长期仓位配置」研究的**数据、结论与可视化整合仓库**（公开分享 + 资料备份版）。

研究主线：
- **中国（CN）**：2008 年起月度宏观状态面板 → 变量特征工程 → 宏观因子/状态 → 与股市长期回报的条件分布研究 → 回测验证；冻结于 Phase2 重清洗 v2。
- **日本（JP）**：1995 年起决策网格 state / 12-target / PIT 序列库（1950s+ 官方与镜像双通道），口径冻结于 JP1.8。
- **JP-HIST（中日结构对比）**：把日本 1954–2026 的长历史（法人资产负债表周期、通缩、地产、人口等）与中国 2000s+ 对照，检验「中国会成为下一个日本吗」这类结构性问题；H0–H5 冻结后，H6-A/H6-B 补采机制变量并冻结（2026-09-08）。

## 快速开始（可视化）

```bash
cd visualization
pip install -r requirements.txt        # streamlit / pandas / plotly（playwright 可选：PNG 导出）
streamlit run app/app.py
```

浏览器打开后可用四视图：🇨🇳 中国数据 / 🇯🇵 日本数据 / ⚖️ 中日对比（月频族 + 年度重点族 + 季度机制族三层）/ 🧭 JP-HIST 结构发现；中、日模块含「补充数据」组（年度/机制季度/通缩季度/原始月度）。
