# JP-HIST H4 v0.3 Robustness & Falsification Gate — 规格（预注册）
日期：2026-09-06
状态：FROZEN（批准后不得根据输出移动区间/阈值）
依据：外部审核 JP-HIST_H1P1_H4v02_外部审核及下一阶段方向（§9-11）+ 用户授权批 1
性质：**预注册式证伪检验**——主动让假设失败，观察其是否存活

## 1. 冻结假设（H4-HYP-02，candidate hypothesis）
- **HYP-A（fixed-lag）**：在 retrospective structural-state metric 下，CN 2000-2025 与 JP 1970-2025 的窗口级固定 lag 相似度中心在 **L≈21-22**（B/C/D 窗一致）；A 窗（2000-2012）为参照不要求一致（早窗机制不同）。
- **HYP-B（dual-cluster）**：CN 2013-2025 逐年 best-match 呈双簇——主体 **JP 1991-1998** + 尾部若干年 **JP 2003-2011**，而非单一固定平移。
- 注意：HYP-A 是窗口级 fixed-lag 命题；HYP-B 是逐年 nearest-state 命题。二者不同层级，独立检验、独立判定。

## 2. 冻结 search space（禁移动）
- CN years: 2000-2025（窗 A 2000-2012 / B 2005-2015 / C 2010-2020 / D 2015-2025 为报告窗）
- JP years: 1970-2025
- lag search: 10-45（逐年 + 窗口平均）
- 模块: GROWTH/INFLATION/MONEY_CREDIT/EXTERNAL/DEMOGRAPHY_LABOR（PROPERTY_ASSET 因 crosswalk 无 A/B 对不在主检验——单独 descriptive 处理）
- 变量: cn_jp_concept_crosswalk A/B 级（CN 侧用 h1p1_extension 延伸；birth_rate 用 ΔCBR）

## 3. 冻结参数
- coverage_rule_id: CR-2026-09 —— total coverage = 存活模块数/eligible 模块数 ≥70% 且 ≥4 模块；module coverage = 有值 A/B 对/期望 A/B 对 ≥50%（期望对 = crosswalk A/B 中双侧变量存在且目标年应有值）
- module weight: 等权（存活模块均值）
- metric 三套 + 1 辅助：RANKSTATE（主）/ MANHATTAN / EUCLID（standardized）/ PERCENTILE（辅助）
- normalization grid（JP/CN 双侧适用，除非标注）：
  1. robust-z full-sample JP 1970-2000（对照——旧标定）
  2. robust-z full-sample JP 1970-2025（主）
  3. expanding robust z（至 t 为止）
  4. rolling robust z（20y 窗）
  5. percentile rank（full-sample）
  6. no-normalization standardized distance（z 直用原始 standardized 值距——实际=Manhattan on raw）
- null（10,000 reps）：block permutation（JP 3y 块）→ 每 rep 全 lag/nearest-state 搜索取 max → max-null 分布；另 contiguous random windows
- leave-one-module-out: 5 种（每次去 1 模块）

## 4. 判定标准（Confirmed Structural Correspondence，审核 §11 七条件）
H4-HYP-02 升级 SUPPORTED/ROBUST 需同时满足：
1. 严格 coverage gate PASS（CR-2026-09）
2. ≥2/3 metric 支持相同 lag 区间（21-22 ±2）
3. block/max-statistic null 显著（obs max > 95% max-null）
4. leave-one-module-out 不由单一模块驱动（去任一模块 21-22 或双簇至少一仍存）
5. normalization grid 中 lag 中心无大幅漂移（<±4y 偏移）
6. dual-cluster bootstrap 稳定性（每 CN 年簇归属概率，见 Step 9）
7. definition-break sensitivity 不改变核心方向
不满足 → 结论降维（module-specific/regime-specific/non-fixed-lag 或否定），不视为失败

## 5. 表述纪律
- "稳定 21-22" 仅指窗口级 fixed-lag average；逐年 nearest-state 单独报告波动（lag SD、IQR）
- 双簇为 best-match 分布的描述；未经 Step 9 bootstrap 不得称"确认"
