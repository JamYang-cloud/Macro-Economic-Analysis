# H6-B B1 Batch 1 采集规约（子代理共享上下文，2026-09-07）

本文件是所有 B1 子代理的强制约束与输出规范。开工前必读。任何与冻结 spec 冲突的动作=违规。

## 0. 项目路径（WSL）
- 项目根：本地项目/宏观股市罗盘_日本/08_jp_hist
- B1 raw 落盘：<根>/h6/01_raw/jp/{provider}/ 与 h6/01_raw/cn/{provider}/（provider=boj_ffa/mof_corporate/mlit_property/esri/nbs_property/nbs_corporate/pboc/bis_credit/bis_property_price）
- 标准化输出：<根>/h6/02_standardized/h6b/（文件前缀 h6b_q_ = quarterly；h6b_a_ = annual）
- 引擎脚本暂存：/tmp/h6b_b1_*.py（用 write_file 落脚本 → `python3 /tmp/xxx.py` 执行；禁 heredoc/`-c` 长命令，会触发审批超时）
- 环境：系统 python3 有 pandas/xlrd/openpyxl/csv；沙箱无网络代理需直连

## 2. 冻结约束（违反即废）
- source cutoff = 2026-08-31：只取该日前官方发布数据；raw 的 retrieved_at 记真实抓取时间
- quarterly 主频：stock=quarter-end / flow=quarter sum / index=quarter avg
- CN 房地产 YTD 累计必须先还原单季流量 Flow_m = YTD_m − YTD_{m−1}，禁直接平均累计值
- 禁插值过 missing gate；禁 NA→0；禁 level concat（跨 definition regime 用 growth 拼）
- 禁改动 spec/registry 任何冻结值；发现数据不可得 → 标 GAP/INFEASIBLE 如实上报，禁伪造、禁找二手替代不记录
- definition break 必须记录（来源换口径/起点/覆盖变化）

## 3. 输出 CSV schema（标准化文件）
列：quarter（或 year）,value,variable,country,unit,source_note
- quarter 格式 YYYY-Qn（如 1985-Q1）；annual 用 year 列
- value 为 float（round 6）；禁字符串数字混合
- source_note 写：机构+表名+口径+覆盖段（如 "BOJ FFA NFC financial liabilities Q 1980Q1-2026Q2"）
- UTF-8-sig 编码（Excel 友好），与项目既有 h6b_q_corporate_leverage.csv 一致

## 4. 主窗与覆盖报告
- JP primary：1985Q1-2005Q4（84 季）；long-window：1970Q1+（如变量可得）
- CN primary：2010Q1-2026Q2（cutoff 前最新，约 66 季）；extended：2005Q1+
- 每个标准化文件须报告窗内 obs 数（如 "window obs 84/84"）

## 5. 质量锚点（经济史验证，输出前必核）
- JP：1990 泡沫顶峰杠杆高→2000s 去杠杆；利息负担 1990 高（~0.96）→2005 低（~0.13 零利率）
- CN：2011 地产投资峰值；2013 后房价放缓；2021-22 地产下行（恒大/断供）；企业中长期贷款增速 2010s 高→近年降

## 6. 交付物与回报格式（每个子代理完成时）
1. raw 清单：variable_id / provider / source_url / retrieved_at / raw 文件路径 / sha256 / 原始字节数
2. 标准化清单：variable_id / 输出文件路径 / 季度数 / 主窗 obs / 锚点验证结果
3. definition_break / coverage 备注
4. 阻塞项与建议（GAP/INFEASIBLE 如实标，禁编数）
5. 若某源完全不可得 → 明确说"该变量 B1 不可得=INFEASIBLE_AFTER_PRESPECIFIED_MASK 候选"，不要硬凑
