## 一、根目录治理文件

### 1.1 variable_registry_v2.csv（变量注册表，104 行 × 35 列）

**含义**：全项目唯一权威的变量目录——每个变量的来源、口径、频率、PIT 规则、模型准入资格。任何层级的脚本都以它为准。
**用途**：标准化脚本读它确定取数；Step 2.7 读它做 REVISED hard exclusion；Phase 3/4 读它做模型准入。

| 字段 | 说明 |
|---|---|
| variable_id | 唯一标识（`域.名称`，如 inf.cpi_yoy） |
| variable_name_cn | 中文名 |
| variable_role | RAW_FEATURE / DERIVED / TARGET_SOURCE / EVENT_STATE |
| direct_model_use | TRUE/FALSE 是否可直接入模型 |
| canonical_source | 主源文件（data_raw_v4/ 或 manual_*） |
| source_date_column / source_value_column | 源文件日期列/值列名 |
| series_filter | 行级过滤条件（如存款口径 regime 选择） |
| source_owner | 数据来源机构（统计局/央行/东财…） |
| definition_regime | 口径定义（如 M1_PRE_2025） |
| frequency | monthly / quarterly / annual / event / MIXED |
| unit | 单位（%/亿元/点…） |
| release_rule_code | PIT 发布规则（T0_CLOSE / EVENT_ANNOUNCEMENT / CONSERVATIVE_MONTH_20D / FOREIGN_MARKET_T1_ASIA…） |
| max_stale_months | 新鲜度上限（0=不允许陈旧，2=允许 2 个月） |
| pit_eligible / backtest_eligible | 是否可进 PIT / 回测（REVISED_HISTORY 变量=FALSE） |
| observed_start / observed_end | 实际观测范围 |

### 1.2 expected_diff_manifest.csv（预期变更清单，28 行 × 6 列）

**含义**：重清洗相对 v1 的**全部预期变化**（补缺/换主源/新增/重命名）。QC 判断公式：`(实际 diff) − (预期 diff) = 0`。
**用途**：机器验证"重清洗只改该改的"。字段：variable_or_artifact / expected_change / reason / expected_start / expected_end / expected_keys（离散月列表）。

## 二、Step 2.2 标准化层（standardized_v2/）

### 2.1 standardized_all.csv（76 变量 × 99,490 行，24 列）—— 管道基石

**含义**：从 33 个原始文件提取的**观测级**标准化长表。一行 = 一个变量的一个参考期观测（含其全部溯源元数据）。
**用途**：所有下游（PIT/月度/特征）的唯一起点；问题排查时回到这一层看"某个值来自哪个源文件"。

| 字段 | 说明 |
|---|---|
| variable_id | 变量标识 |
| reference_period | 参考期（YYYY-MM；年度=YYYY-FY；季度=YYYY-Qn） |
| observation_date | 观测日（日频/事件数据用） |
| value | 数值（字符串存储，保留原始精度） |
| unit | 单位 |
| source_file | 来源文件（可追溯到 data_raw_v4/ 或 manual_*） |
| quality_grade | 质量等级 |
| definition_regime | 行级口径（AFRE 六种 regime、M1 新旧等） |
| release_date / release_date_imputed | 官方发布日 / 是否推算 |
| source_url / source_reference | 溯源链接/说明 |
| note | 备注 |
| available_date | 数据可得日（源自带时保留，如 afre 追溯段 2020-01-31） |
| vintage_status | CURRENT / RETROSPECTIVE_HISTORICAL_RELEASE / REVISED_HISTORY… |
| pit_use_status | PIT 可用性状态 |
| revision_status / verification_status | 修订/核实标记 |
| snapshot_type | 快照类型（月末 vs LATEST_AVAILABLE_INTRAMONTH） |
| institution_scope | 机构维度（rrr 大行/中小行） |
| trade_date | 事件生效日（rrr 分批生效） |

**主键语义**：multi-vintage 变量（export/import 等）= (variable_id, reference_period, release_date)；rrr 事件 = (variable_id, observation_date, institution_scope, trade_date)。

### 2.2 standardized_summary.csv（77 行 × 8 列）

**含义**：每变量的标准化统计（多源合并后）。字段：variable_id / primary_source / primary_source_rows / source_count / source_set / merged_std_rows / date_fail / conflicts。

### 2.3 standardized_missingness.csv（86 行 × 6 列）—— source-level

**含义**：按 (variable, source_file) 的源级缺失统计。字段：variable_id / source_file / source_rows（源文件行数）/ observed_rows（进主表行数）/ omitted_null_rows / filter_reason（过滤原因，如空值/structural NA/intramonth 排除）。

## 三、Step 2.3 PIT 层（pit_v2/）

### 3.1 pit_all.csv（99,490 行 × 27 列）

**含义**：standardized_all + **PIT 可用日期**。每行多了 available_date（该值何时可被决策者知道）、available_date_imputed、vintage_status、vintage_quality、pit_rule。
**用途**：B 类特征（afre_yoy/loans_12m/fr007_p90）回读 PIT 重建历史；execution calendar 取 mkt.hs300_price 观测日。

| 关键字段 | 说明 |
|---|---|
| available_date | 数据可用日（≤ 决策日才可见） |
| available_date_imputed | 是否推算（0=官方/1=保守推算） |
| vintage_quality | REALTIME_VINTAGE / LATEST_HISTORY_PROXY / RETROSPECTIVE_COMPARABLE |
| pit_rule | 计算规则（OFFICIAL_RELEASE / CONSERVATIVE_MONTH_20D / T0_CLOSE / EVENT_ANNOUNCEMENT / SOURCE_AVAILABLE_DATE…） |

### 3.2 pit_rule_summary.csv（85 行） / pit_rule_vintage_crosstab.csv（9 行）

**含义**：变量×PIT 规则的统计汇总与 vintage 交叉表。用途：PIT 规则审计。

## 四、Step 2.4 月度层（monthly_v2/）

### 4.1 decision_dates.csv（223 行 × 2 列）—— 决策日历

**含义**：2008-01 ~ 2026-07 每月末 A 股交易日 = 决策日。**全管道的时间基准**。
**用途**：任何"某月某变量可用值"都以 decision_date 为门槛；目标计算以它为锚。

### 4.2 monthly_panel_long.csv（18,174 行 × 15 列）—— 月度长表

**含义**：每 (决策月, 变量, 聚合方式) 一行：as-of 选出的值 + 用的哪个参考期/哪个版本的 available。
**用途**：特征重建（delta_pmi 连续参考期判断）、缺失 reason 溯源、调试。

| 关键字段 | 说明 |
|---|---|
| aggregation | last_known / monthly_mean / effective / announced |
| value | as-of 选定值（空=NA） |
| available_date_used | 实际用的可用日（≤decision_date） |
| reference_period_used | 实际用的参考期（last-known 语义核心） |
| na_reason | NOT_RELEASED / STALE_SOURCE / COVERAGE_LOW / SOURCE_GAP… |
| stale_age_months | 陈旧月数（Month(decision)−Month(available)） |
| last_known_value | 最后已知值（NA 时保留 traceability） |

### 4.3 monthly_raw_state_panel.csv（223 月 × 76 列）—— 状态宽表

**含义**：决策月 × 74 个状态变量的宽表（REVISED_HISTORY 变量已 hard exclude；rrr_events_em/m1_new 不含）。一行=一个决策月的完整宏观状态快照。
**用途**：baseline 8 个 raw states 直接取数；current_state 快照来源；可视化主数据源。

### 4.4 rrr_announced_monthly.csv / rrr_effective_monthly.csv（各 223 行 × 15 列）

**含义**：存款准备金率双语义月度序列——announced（公告口径）/ effective（生效口径）。字段同 monthly_panel_long。

## 五、Step 2.5 特征层（features_v2/）

### 5.1 feature_panel_raw_precision.csv（223 × 11）—— **模型数值唯一合法来源**

**含义**：10 特征 × 223 决策月，**原始精度**（未舍入）。
**铁律**：Phase 3 percentile/z-score/estimator **只能读这个文件**，禁止读展示版。

### 5.2 feature_panel.csv（223 × 11）

**含义**：同一数据的 4 位小数展示版。仅用于人工查看/图表。`round(raw_precision,4) == feature_panel` 已机器验证。

### 5.3 feature_long.csv（2,230 行 × 8 列）

**含义**：特征长表（含每月的 NA reason、参考期、available、regime）。
**用途**：missingness 继承；regime 审计；no-lookahead 验证。

| 关键字段 | 说明 |
|---|---|
| feature | 特征名（ey/eyg/term_spread/pmi_gap/delta_pmi/m1_m2_gap/afre_yoy/loans_12m/fr007_p90/fr007_vol） |
| na_reason | NOT_RELEASED / STALE_SOURCE / INSUFFICIENT_HISTORY… |
| feature_regime | 归一化 regime（M1_PRE_2025/M1_2025_NEW；AFRE_LEGACY_HISTORICAL/AFRE_PRE_2017/AFRE_POST_2019/AFRE_POST_2023…） |

### 5.4 feature_registry.csv（11 行 × 10 列）

**含义**：特征定义表（公式/依赖/模型 tier/归一化 regime）。afre_yoy_derived 行 feature_role=VALIDATION_LINEAGE（不进模型）。

### 5.5 afre_yoy_derived.csv（223 行 × 5 列）

**含义**：社融存量同比的**旧派生法**序列（100×(TSF_t/TSF_t-12−1)），保留为 validation lineage——与官方主源 afre_yoy 对照用，**不进 feature_panel**。

## 六、Step 2.6 缺失层（missingness_v2/）

### 6.1 missing_matrix.csv（223 × 85）—— 缺失原因权威矩阵

**含义**：84 对象（74 状态 + 10 特征）× 223 决策月的 NA reason（空=有值）。
**铁律**：Step 2.7 dataset build 逐月筛选**只读这个文件**；coverage_report 仅审计摘要。
**reason 枚举**：NOT_APPLICABLE / NOT_RELEASED / SOURCE_GAP / COVERAGE_LOW / STALE_SOURCE / LEGACY_REGIME / RETROSPECTIVE_NOT_AVAILABLE / INSUFFICIENT_HISTORY / HISTORY_SNAPSHOT_ONLY / HANDOFF_TO_QUARTERLY

### 6.2 coverage_report.csv（84 行 × 22 列）

**含义**：每变量覆盖率报告（观测起止/非空数/各 reason 计数/风险）。
**关键字段**：all_na_segments（**全部**连续 NA 段，完整切分）/ major_structural_gaps（≥12 月段摘要）/ risk（POST_LAST_VALID+SOURCE_GAP=HIGH）。

### 6.3 missingness_reason_summary.csv / missingness_category_summary.csv

**含义**：细类（reason）与大类（category）聚合统计。category 映射：STALE_SOURCE/COVERAGE_LOW/SOURCE_GAP→SOURCE_GAP；RETROSPECTIVE_NOT_AVAILABLE/LEGACY_REGIME/HANDOFF_TO_QUARTERLY→DEFINITION_BREAK；INSUFFICIENT_HISTORY→NOT_APPLICABLE。

## 八、Step 2.8 目标层（targets_v2/）

### 8.1 targets_long.csv（2,676 行 × 12 列）—— 目标主表

**含义**：223 决策月 × 12 目标（3 周期 36/60/120m × 4 类：state return / execution return / loss_flag / future MDD）。
**关键字段**：

| 字段 | 说明 |
|---|---|
| target_id | forward_{h}m_state / forward_{h}m_execution / loss_flag_{h}m / future_max_drawdown_{h}m |
| value | 目标值（8 位小数；NA 时看 na_reason） |
| na_reason | HORIZON_INCOMPLETE（目标月末未到）/ ENTRY_NOT_AVAILABLE |
| state_start_date | = decision_date（state 锚） |
| execution_entry_date | 决策日后第一个 A 股交易日（execution 锚） |
| target_end_date | 目标月最后一个 H00300 交易日 |
| path_n_obs | MDD 路径观测天数 |
| observed_data_end_date | 仅 incomplete 行：数据观察末端（2026-08-25） |

**公式**：state = TR(月末)/TR(决策日)−1；execution = TR(月末)/TR(下一交易日)−1；loss = 1{state<0}；MDD = min(TR/cummax(TR)−1) 沿 [决策日, 目标月末]。

### 8.2 targets_wide.csv（223 × 13）—— long 的无损宽视图

### 8.3 target_registry.csv（12 行 × 12 列）—— 目标定义表

**含义**：每个目标的公式/锚类型/entry/end 规则/na 规则/依赖。机器可读。

### 8.4 dataset_horizon_eligibility.csv（12 行 × 8 列）

**含义**：4 个模型配置 × 3 周期的可用样本量（n_predictor_complete / n_target_complete / n_joint_complete / 首末联合月）。
**注意**：这些是重叠观测数，**不是独立样本**——Phase 4 须 walk-forward/block bootstrap/effective sample size。
